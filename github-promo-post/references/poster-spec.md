# GitHub 推广海报 — 生成范式与校验规范（poster-spec）

> 权威规范。生成器（build_v3.py）必须遵守「生成逻辑」，交付前必须通过「校验逻辑」（scripts/validate_poster.py + 视觉复核）。
> 违反任一条 = 不合格，禁止交付。

## 1. 画布与版式范式

| 项 | 规范 | 备注 |
|---|---|---|
| 尺寸 | **1080×1440**（3:4 竖版） | 精确，PIL resize 后必须复核 |
| 内边距 | 72px 顶 / 76px 左右 / 64px 底 | poster padding，内容不出血 |
| 结构 | 三明治：头栏(top) + 内容区(flex:1) + 底部条(strip, margin-top:auto) | 所有卡统一 |
| 布局 | 全部流式（flex/grid）；**禁绝对定位堆叠内容**（装饰可 absolute 但只放背景层） | 文字重叠红线 |
| 垂直居中 | 内容区 `flex:1 + align-content:center`（或 justify-content:center） | 禁 flex:1 拉伸稀疏内容 |
| 装饰 | noise 0.04 / grid 线 5% / 水印 opacity ≤0.06，均低对比不参与内容判定 | 不与文字区重叠、不出血 |

## 2. 字号阶梯（1080×1440 卡）

| 层级 | 字号 | 用途 |
|---|---|---|
| 主标题 | **80–98px** | 大标题（≤2 行，每行 ≤10 汉字 @98px / ≤12 @80px，928px 内容宽） |
| 内容主元素 | **30–40px** | 卡片标题、代码块、步骤标题、节点文字 |
| 正文 | **24–28px** | 卡片说明、卖点描述 |
| 辅助 | **18–26px** | 典型场景、关键词 chips、底部条、小标签 |
| 行高 | 标题 ≥1.25（雅黑字形 1.32em 防重叠）；代码 1.5–1.6 | |

**铁律**：元素偏小（标题 60px、正文 20px）＝「中间大面积空白」根因 → 修法 = 放大字号/padding 让内容自然撑满，**禁止 flex 拉伸**。

## 3. 配色范式

| 用途 | 值 | 备注 |
|---|---|---|
| 深底 A | `#0E1630` | 默认深海军蓝 |
| 深底 B | `#002FA7` | 亮深蓝（封面/对比卡变体） |
| readMD 强调 | `#E8FF00` 荧光黄 | 全套 readMD 卡统一 |
| doAI 强调 | `#22D3EE` 荧光青 | 全套 doAI 卡统一 |
| 代码块底 | `#0a0a12` | mock/代码 |
| CTA 满版底 | 强调色（黄/青） + `#0E1630` 字 | 仅 CTA 卡 |

**铁律**：一套卡组只允许一个强调色；多套卡组必须同设计系统（同底同版式，仅强调色不同）。

## 4. 内容规范

- 卡内**禁止真实 URL**（限流红线）；GitHub 引导 =「GitHub 搜 **用户名/项目名**」（用户名在前）
- 标题 ≤15 字（信息流 0.5-1s 可读）；正文卡信息密度高、无空洞
- 英文术语（YAML/HITL/LLM/Agent）发布前 grep 自查拼写
- 左右对比卡：代码行数对齐（如各 5 行）

## 5. 校验逻辑（交付门槛）

### 5.1 脚本校验 — `python scripts/validate_poster.py <img|dir>`（必须全 PASS）

| 检查项 | 阈值 | 捕获的问题 |
|---|---|---|
| size | 精确 1080×1440 | 尺寸错误 |
| edge_clean | 四边 4px 带内容像素 < 2% | 白边/黑边/截图残留 |
| coverage | 内容像素 ≥ 22% | 整卡太空 |
| **blank_band** | **最大连续空白行带 ≤ 120px** | **中间大面积空白（核心）** |
| bottom_gap | 最底内容距底 ≤ 90px | 底部截断/悬空 |
| top_gap | 最顶内容距顶 ≤ 220px | 头部空荡 |
| side_clear | 左右 8px 带内容 < 1% | 出血/贴边 |

背景判定：四角 12×12 平均色；像素色差 > 40 = 内容。装饰层自动忽略。
阈值可 `--thresholds key=value` 覆盖；`--json` 机器可读；exit 0/1 供 CI。

### 5.2 视觉复核 — vision_analyze 逐张（必须全过）

固定五问：①文字重叠？②大面积空白？③底部完整？④白边/截断？⑤主要排版问题？
脚本校验抓像素级缺陷，视觉复核抓语义级缺陷（重叠/误读/美观），**两者互补缺一不可**。

### 5.3 生成器自检

- 截图后 PIL 非黑 bbox 裁剪 → resize 1080×1440 → 输出前断言尺寸与边缘
- 生成器末尾自动调用校验脚本，FAIL 即 exit 1 并打印报告

## 6. 生成链路（不可跳步）

1. 内容按素材卡（references/projects.md）组织
2. build_v3.py 生成 12 卡（HTML → Edge 大窗口截图 → PIL 裁剪 resize）
3. `python scripts/validate_poster.py output目录` → 全 PASS
4. vision_analyze 逐张五问复核
5. 两步都过 → 交付；任一 FAIL → 修复后重跑 3-4
