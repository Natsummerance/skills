# 人称/称谓替换模板（内置）

适用：把「说话人对 A 的讲述/转述」改写成「说话人对 B 的重述」。参考案例：女朋友对男朋友的微信转述 → 女朋友对爸爸重述。

## 替换矩阵

| 原文 | 替换 |
|---|---|
| 我 | 我 |
| 你（指原接收者，如男朋友） | 他 |
| 他（已指目标第三人，如男朋友） | 他（不变） |
| 你（口语自指，指说话人自己） | 我 |
| 我妈 | 妈妈（除非「妈」指当前聊天对象 → 爸爸） |
| 我爸 | 爸爸 |
| 我爸妈（直接对目标对象说话时） | 你们 |
| 你妈 / 你妈妈 | 他妈妈 |
| 你爸 | 他爸爸 |
| 你爸妈 / 你爸爸妈妈 | 他爸妈 / 他爸爸妈妈 |
| 原文用「他」指长辈/妈妈类角色 | 她 / 妈妈（避免与男主的「他」混淆） |

## 语境消歧规则

1. 原文里「你」可能指不同人：逐处判断指代（原接收者 / 说话人自指 / 第三方），再按矩阵替换；每处判断记入变更记录。
2. 口语里「他/她」混用：指长辈/妈妈时统一为「她/妈妈」；指男朋友/男主时保持「他」。
3. 「我爸妈」在直接对目标对象（如爸爸）说话时改「你们」；仍在转述第三人时按语境处理。

## 轻顺稿边界

- 保留：原话结构、「我说/就是/嗯」等语气词、重复、口语瑕疵（人名混写等）。
- 可最小修顺（必须记录）：明显录入错误（叠字如「你你也」「离离」「在在」、残句句尾多字、口语错字）。
- 禁止：改人名地名时间数字事件、新增内容、改写原意、AI 化润色。

## 校验清单

- 「你」全量扫描：每个「你」都有去处（→他 / →我 / →你们），并注明理由。
- 称谓三不混：妈妈 / 他妈妈 / 爸爸 不串线。
- 指代一致性：同一段落内各角色称谓稳定。
- 保真度：逐句 diff，只允许替换与最小修顺差异。
- 可读性抽检：抽 3-5 句，站在目标听众角度确认能听懂。

## 参考案例（脱敏示例）

原文（对 A 说）：「我说我爸妈不放心我跟女生出去玩。我说你可能会来陪我，你妈也问了我爸的态度。」
改写（对 B 重述）：「我说你们不放心我跟女生出去玩。我说他可能会来陪我，他妈妈也问了爸爸的态度。」
