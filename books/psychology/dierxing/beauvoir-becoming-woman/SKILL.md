# 波伏娃式思考 · 总纲引擎

> 蒸馏自西蒙娜·德·波伏瓦《第二性Ⅰ》（郑克鲁译）导言。本书是存在主义女性主义的奠基文本；本 skill 抽取其概念骨架——不是书摘，而是一套可复用的「身份如何被处境塑造」分析框架。原文存 `knowledge/book-library/distill/dierxing1/`。

## When to Use

- 用户讨论性别议题：女性气质、性别不平等、「女人该怎样」类话语
- 用户想分析任何「某群体是天生的还是被造就的」问题（可迁移到阶层、种族、职业身份）
- 用户需要区分「抽象平等」与「具体处境」的论述漏洞
- **Don't use for**：识别单因素归因谬误（用 `beauvoir-three-reductions`）；父权制历史机制（用 `beauvoir-patriarchy-history`）；文学中的女性神话个案（用 `beauvoir-myth-decode`）

## 核心命题（I）

1. **女人不是天生的，而是被塑造成的**：「女人不是天生的，而是后天形成的」（Ⅱ卷开篇重申，Ⅰ导言以处境论全程论证）。生物学的「雌性」不等于社会意义的「女人」——后者是被处境一步步训练出来的（导言）。
2. **女人是他者（the Other）**：「男人是主体，是绝对，而女人是他者」。人类意识天然分自我/他者，但其他对立群体（阶级、种族）的从属有历史事件可考，「女人却始终存在」，从属无事件起点，故他性显得像绝对宿命（导言第3节）。
3. **女性气质不存在**：「今日之所以不再有女性气质，是因为从来就没有女性气质」——生物学与社会科学已不再相信固定实体，特性是对**处境**的次要反应（导言第1节）。
4. **女人不说「我们」**：无产者说「我们」，黑人说「我们」，女人分散地生活在男人中间，「通过居所、工作、经济利益……联结起来，比和其他女人联结得更紧密」——无法汇聚成对抗整体的群体，这是解放难于其他受压迫者的结构性原因（导言第4节）。
5. **共谋结构**：主人提出需要但不受制于需要，奴隶把对主人的需要内化。「将女人确定为『他者』的男人，会发现女人扮演了同谋的角色」——回避自由的形而上危险，换取保护者的物质庇护（导言第5节）。
6. **评判标准是自由而非幸福**：拒绝用「闺房中的女人难道不比一个女选民更幸福吗」论证——「决不可能衡量他人的幸福」；本书采用存在主义道德观，以个体获得的具体**自由**机遇为尺度（导言倒数第2节）。

## E — 可执行步骤

### 流程 A：处境分析（波伏娃四问）
1. 这个身份特征被说成「天生/自然」时——问：它是生理事实，还是对处境的反应？
2. 这个群体能否说「我们」？它的成员是横向团结，还是分散依附于支配群体成员？
3. 支配方与这个群体的相互性是否存在？（他者能否同样把支配方界定为他者？）
4. 该群体的「选择」里有多少是共谋（回避自由换庇护），多少是真选择？

### 流程 B：拆解「有差别的平等」话语
1. 听到「女人同男人是平等的，她们没有什么可要求的同时又说，女人永远不会同男人一样」——标注：这是导言点名的双面话术（平时援引抽象平等，冲突时翻出具体能力差）。
2. 追问具体处境：谁掌握岗位、工资、继承权、教育传统的威信？
3. 用「就是即变成」破循环论证：「大体上，女人今日就是低男人一等」「当一个个体或者一群个体被控制在低人一等的处境中，事实是他或他们就是低人一等的」——萧伯纳擦鞋例：把黑人降低到擦皮鞋的一类人中，由此得出黑人只能擦皮鞋（萧伯纳擦鞋例：把黑人降低到擦皮鞋的一类人中，由此得出黑人只能擦皮鞋）——萧伯纳擦鞋例。现状不能证明应然。

## B — 边界

- 本 skill 是**存在主义视角的一家之言**：波伏娃明确自陈「没有一定之见是不可能谈论任何人类问题的」，其伦理背景（超越性/内在性）是设定而非公理。
- 波伏娃的部分经验论断受 1949 年时代局限（如工人阶级内部性别竞争的表述），引用时应带年代标注。
- 与本族 skills 解耦：三还原论诊断管「归因方法批判」；历史机制管「从属怎么来的」；神话解码管「文化符号怎么运作」——本 skill 只管总纲与分析姿态。
- 不适用于：生物学性别差异的实证科学讨论；需要引用当代性别研究前沿时（本书是 1949 文本）。
