# 三还原论诊断 · 单因素归因识别器

> 蒸馏自《第二性Ⅰ》第一部「命运」三章（郑克鲁译）。波伏娃逐一检审生物学、精神分析、历史唯物主义三种理论，每章结构相同：承认其贡献 → 指出其根本局限 → 以存在主义处境论收束。本 skill 把这个三连击抽成通用诊断工具。原文存 `knowledge/book-library/distill/dierxing1/`。

## When to Use

- 用户遇到「女人天生如此」「都是潜意识作祟」「归根结底是经济问题」类单因素解释
- 用户在写论文/做辩论，需要评估某个理论的解释力边界
- 需要判断某学科视角（生理/心理/经济）何时够用、何时越界
- **Don't use for**：学习波伏娃总纲思想（用 `beauvoir-becoming-woman`）；父权制具体历史（用 `beauvoir-patriarchy-history`）

## 核心命题（I）

1. **生物学的贡献与局限**：身体是处境——「如果身体不是一件东西，它就是一种处境」（引梅洛-庞蒂）；女人的体力弱、生育负担是「女人处境的一个本质的因素」。但这些事实本身没有意义：「它们不足以确定性别的等级；它们不能解释为什么女人是他者」。脑重量比较（1220g vs 1360g）是「无益讨论」的标本——「只有从人的观点出发，才能将女人与男人做比较……人不是一种自然物种，而是一种历史观点」（ch.1 末节）。
2. **精神分析的贡献与局限**：进步在于「主体体验过的身体才是具体地存在的」；但弗洛伊德从男性模板推导女性命运，「阴茎嫉妒」预设了对男性特征的预先评价而非解释它。「精神分析将权威替代价值，将冲动替代选择」——拒绝选择概念使它无法解释禁忌的根源（弗洛伊德自认无法解释父权权威的来源）（ch.2）。
3. **历史唯物主义的贡献与局限**：恩格斯把女性史绑定技术史是对的——「技术消除了男女体力上的不平等」，体力劣势只在需要重体力的工具水平上才成为劣势。但从私有制「推断」对妇女的压迫是循环论证：「他非常明白，女人体力的弱点只是在与青铜工具和铁工具的关系中才变成具体的劣势，但是，他没有看到女人劳动能力的局限本身，只是从某种角度看才构成具体的不利」——计划先于工具（ch.3 第2节）。
4. **双重一元论一并拒绝**：「我们以同样的理由拒绝弗洛伊德的性一元论和恩格斯的经济一元论」——「“阴蒂的”或“阴道的”范畴就像“资产阶级的”或“无产阶级的”范畴一样，同样无法禁闭一个具体的女人」。身体、性、技术「只有在人以存在的总体观点把握它们的时候，才具体地存在」（ch.3 末节）。

## E — 可执行步骤

### 三问诊断法（遇到任何单因素归因时）
1. **找事实内核**：该理论说对了什么？（波伏娃从不全盘否定：生物差异实在、童年经验实在、经济结构实在）
2. **测推理方向**：它是从「事实→意义」还是偷偷从「意义→事实」？精神分析用社会赋予的价值解释器官羡慕（循环）；恩格斯用工具解释压迫却没解释为何要用工具征服（缺本体论前提）。
3. **查禁闭范围**：该因素能否禁闭具体的个人？任何单因素框架都处理不了「个体选择」——「我们将把女人放在价值世界中，给予女人的行为以自由的维度」（ch.2 末节）。

### 迁移应用
- 见到「基因决定论」论述 → 套用 ch.1 模板：生理事实 ≠ 等级结论，意义由目的与制度赋予
- 见到「一切皆童年创伤」 → 套用 ch.2 模板：权威替代价值 = 解释力假象
- 见到「归根结底是阶级/钱的问题」 → 套用 ch.3 模板：抽象实体吞不掉个体命运（怀孕不能简单比做服兵役）

## B — 边界

- 本 skill 是**方法论批判工具**，不提供正面理论——正面框架（处境论、自由尺度）在 `beauvoir-becoming-woman`。
- 波伏娃对精神分析/马克思主义的转述带 1949 年语境与论战色彩；当代两学科已远非当年形态，引用时应标明她批评的是哪一历史版本。
- 「三问诊断」是从三章结构归纳的操作化，命题部分才是原文直接对应。
- 不适用于：临床心理学实务；马克思主义政治经济学专业讨论（此处仅涉《家庭、私有制和国家的起源》一章的批判）。
