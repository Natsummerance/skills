# 盛唐诗人画像法 · 讲透一位诗人

> 蒸馏自戴建业《戴老师魔性诗词课》+《钱锺书选唐诗》（杨绛抄录本）的选家视野。定位：**把诗人当「人」讲活**——个体气质、师承交游、语言个性，服务教学讲解与个体理解。原文存 `knowledge/book-library/distill/poetry_appreciation/`。

## When to Use

- 给某位唐代诗人做讲解/画像卡（gaokao 语文作家作品常识）
- 学生问「李白和杜甫到底差在哪」「为什么说王维是诗佛」
- 做诗人专题歌单/文章需要人物细节
- **Don't use for**：单首词的深度赏析（用 cihua-jingjie-method）

## 核心命题（I）

1. **李白：天才的章法推进**：「'桃花潭水深千尺'，本来就够深的了，要是一般的诗人就写成，'恰似汪伦送我情'。但李白就是天才，他还要转进一层，'不及汪伦送我情'……他突然用了两个字'不及'，就又推进一层。层层向前推进，章法实在是太好」（戴建业·赠汪伦）——天才不在奇字而在章法的递进。
2. **诗仙的另一面：情圣**：「李白的有些乐府诗，写景旖旎明丽，写情一语百媚。诗仙原来还是个情圣」——《采莲曲》「紫骝嘶入落花去，见此踟蹰空断肠」（戴建业第29节）——标签化认知（诗仙=豪放）遮蔽了多面性。
3. **杜甫：诗圣是被「炼」成的**：「杜甫在遇上李白以前，身上看不到受道教影响的痕迹。他到王屋山、东蒙山求仙访道，主要是因为李白。李白是他的兄长……就一起去访道了」（戴建业第5节）——杜甫的人格与诗艺是关系与经历塑造的结果，非天生定型。
4. **王维 vs 杜甫的语言顺序**：「像王维的'漠漠水田飞白鹭，阴阴夏木啭黄鹂'，一看就知道，他的语言顺序非常规范，和口语隔得不远……他对自然、对田园的感受实在是太美」；对照杜甫的语序变形——语序与口语的距离是辨析诗人语言的抓手（戴建业）。
5. **诗眼的流变史**：「两汉诗没有诗眼，齐梁初唐诗争一字之工，出现诗眼，盛唐诗又剔除了诗眼，盛唐后期杜诗中再次出现了诗眼。明朝很多人觉得句中有眼，语言就失去了质朴、自然、浑厚的气象……诗眼的优劣不可一概而论」（戴建业）。
6. **选家的眼光即批评**：《钱锺书选唐诗》「钱锺书遴选、杨绛抄录，呈现品读唐诗的独特视野」；杨绛记：「锺书选诗按照自己的标准，选目由他自定，例如他不选文天祥《正气歌》，是很大胆的不选」（出版说明引）——选本的删与留都是文学判断。

## E — 可执行步骤

### 给诗人做画像卡（六格）
1. **标签与反标签**：通行标签（诗仙/诗圣/诗佛）+ 一个打破标签的细节（如李白情圣面）。
2. **关键关系**：师友交游如何塑造他（李白之于杜甫的求仙访道）。
3. **语言指纹**：他的句法与口语的距离、标志性意象群。
4. **代表作品三首**：早/中/晚或三种题材各一。
5. **一句定评**：找一条最精准的古今评语（含出处）。
6. **教学切入点**：学生最容易误解的一点是什么？

## B — 边界

- 戴建业为课堂讲录风格，重趣味启发，学术考证从简；引用其判断需标「戴建业认为」。
- 《钱锺书选唐诗》的价值在选目视野而非注释详备；钱氏不选《正气歌》属个人标准，不宜直接搬入教学定论。
