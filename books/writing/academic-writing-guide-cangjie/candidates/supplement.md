```yaml
- id: f03
  title: 题目-受众匹配框架
  type: framework
  source_chapter: 题目章（海报投稿案例）
  source_quote: |
    "学生把这个研究作为海报展示投稿给孤独症学术会议时，也用了这个题目，结果来看她海报的人寥寥无几。因为在孤独症领域，人们并不关心道德发展。"
  summary: |
    同一研究投不同受众须换题目：道德发展的瞳孔研究
    在发展心理学会是好题目，在孤独症会议无人驻足。
    好题目=核心发现×目标受众的关注点交集。
  tags: [title, audience]

- id: f04
  title: 引用方式选择框架
  type: framework
  source_chapter: 引用章
  source_quote: |
    "在学术写作中，一般用改写（paraphrase）或总结（summarize）的形式来引述别人的观点，很少直接引用文献中的原文……只有以下几种情况例外：（1）表明一个权威支持你的观点。（2）引用别人的观点作为批评的靶子，这时候把原文亮出来就很重要。（3）对于古老的语言的文字（如文言文），直接引用以保…"
  summary: |
    默认改写、例外直引的三情形：权威背书/批评靶子/古语存真。
    直引是高成本动作——每次直引都要问「为什么非原文不可」。
```

## principles（补充）

```yaml
  title: 合作写作1+1>2原则
  type: principle
  source_chapter: 合作章
  source_quote: |
    "通常的方式是一个人先写完，发给另一个人改。这样的合作更高效，适用于双方水平都不低的情况。如果有一方水平较差，初稿很难看懂，那么更适合现场一起写。……合作的原则是'1+1>2'。"
```
