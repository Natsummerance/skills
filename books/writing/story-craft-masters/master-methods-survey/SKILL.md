# 大师创作方法巡礼 · 21 家谱系

> 蒸馏自威廉·凯恩《小说创作大师班》（后浪·文学创作大师班，巴尔扎克到斯蒂芬·金 21 章）。本书方法论：**「模仿」是被现代写作教学遗忘的古典修辞技巧**——逐家拆解可学之处。原文存 `knowledge/book-library/distill/writing_masters/w1_novel_masters.txt`。

## When to Use

- 用户写作卡壳，想知道「哪位大师处理过同类问题」
- 需要为写作课/书评提供创作方法论的谱系参照
- 分析某位作家风格时需要方法层面的归纳语言
- **Don't use for**：文学批评理论（用 literary-reading-lens）；具体场景句法（用 scene-craft-lessons）

## 核心命题（I）

1. **模仿是合法的入门术**：本书开宗明义讲古典修辞学的「模仿」技巧——「这是一本关于如何去'模仿'文学大家的书，而这一技巧在现代教[育中被遗忘]」，给文风「注入新的活力」。（前言）
2. **经历派：毛姆的忠实转化**：「毛姆并没有像寻求轰动效应的新闻记者那样从根本上歪曲或夸大他的经历；相反，他相当忠实地将它们展现出来并写成了小说」——亲身经历不必虚构化，忠实本身就是方法（第7章）。奥威尔自认「对我影响最大的现代作家是萨默塞特·毛姆，我非常佩服他能直截了当、毫不夸张地讲述一个故事」。
3. **选人物先看均衡**：「像毛姆一样选择人物——作者不应随意挑选笔下的人物。选择人物最为重要的原则是他们的类型要均衡，以形成鲜明的对照」（第7章）。
4. **梦境派：卡夫卡的荒诞结构**：「当你有着类似的故事情节，特别是当你的故事线单一并与主流格格不入时，可以尝试研究卡夫卡的文学手法」——让读者「在间接经历中被拽入这个梦境……带领读者领略现代人的荒诞处境」（第9章）。
5. **提炼派：海明威的电报句与冰山**：「如果你想像海明威一样创作，就得避免过多地使用复杂的从句，减少句子里的从属关系」（第12章）；冰山理论——「若作家对他想省略的东西心中有数，也知道省略这部分会强化故事……便可以省略任何一部分」。
6. **重写派的三种改法**：福克纳「对结构进行重新布局」、海明威「对文本进行提炼」、劳伦斯「从里到外对小说进行重写……他会从第一页开始，在空白页重写整个故事！有时，他这样做是为了修正人物间的关系和动机」（第10章 D.H.劳伦斯）。
7. **三分法情节：奥威尔**：「《1984》里的故事分成了三个部分，与亚里士多德对悲剧的开头、中间、结尾的三分法相对应」（第14章）——经典结构论的现代应用。

## E — 可执行步骤

### 写作问题 → 大师方法匹配表
| 你的问题 | 先读谁 | 核心动作 |
|---------|--------|---------|
| 素材只有亲身经历 | 毛姆 | 忠实转化不夸张 |
| 故事线单一易平 | 卡夫卡 | 单线+梦境逻辑 |
| 文字冗长花哨 | 海明威 | 砍从属从句、冰山省略 |
| 结构散乱 | 奥威尔 | 亚氏三分法 |
| 人物扁平 | 福克纳 | 人物复杂化+结构重组 |
| 改稿无从下手 | 劳伦斯 | 整本重写一遍 |

### 使用流程
1. 定位当前最痛的一个问题（只选一个）→ 2. 读对应章节的「如何像 X 一样」小节 → 3. 用该技法改写自己的一段旧稿 → 4. 对照原书例文检查是否走形。

## B — 边界

- 本书是「技法拆解」视角：把名家当作可拆解的技术库，与其文学史地位评价无关；模仿应止于技法，不可抄袭声音。
- 21 家覆盖以欧美男性作家为主（华顿、奥康纳等例外），视角局限需自知。
