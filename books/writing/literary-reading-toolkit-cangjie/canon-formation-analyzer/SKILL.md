# 经典形成分析器

## R — 原文 (Reading)

> "在将一本历史的、哲学的或科学的书归属于'文学'时，我们做的也正是同一种价值判断。"
>
> — 梅勒/多霍斯，伊格尔顿卷·定义之争 + 韦勒克卷·文学史

---

## I — 方法论骨架 (Interpretation)

经典不是天然杰作清单，而是持续的价值判断与制度权力（教育体系/出版市场/批评传统）共同建构的序列。分析一部作品的经典化路径：谁在何时以什么理由把它写入教材选本正典？哪些竞争者被排除？排除的理由今天还成立吗？

---

## A1 — 书中的应用 (Past Application)

### 案例: 文学史边界的移动（定义之争章）
- **问题**: 哲学家为何曾位列文学史？
- **使用**: 经典边界是历史变量——判断标准随制度需求变化。
- **结果**: 今日的文学概念只是当前判断的快照。

---

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 分析某作家经典地位的形成史
2. 质疑或辩护某部入选教材的作品
3. 设计个人阅读书目时的去魅

### 语言信号

- "这本书凭什么是经典"
- "经典书单可信吗"
- "canon formation"

### 与相邻 skill 的区分

- 与 `value-judgment-developer` 的区别: 通用判断分析 vs 专析经典序列
- 与 `qianmu-historical-opinion` 的区别: 钱穆提供非西方经典的内部视角平衡

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **定位入典节点**
   - 完成标准: 找出该作品进入教材选本研究的时间点

2. **提取当时理由**
   - 完成标准: 当时的判断标准是什么

3. **检验今日效力**
   - 完成标准: 那些理由现在还成立吗

4. **输出形成曲线**
   - 完成标准: 经典化的关键事件时间线


---

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用建构论直接贬低经典作品的价值——解释地位来源不等于否认品质

### 作者在书中警告的失败模式

- 把经典形成分析当作推翻教学书目的政治工具

### 作者的盲点 / 时代局限

- 两书对非西方经典形成机制覆盖有限

### 容易混淆的邻近方法论

- value-judgment-developer / qianmu-historical-opinion
