## frameworks

```yaml
- id: f01
  title: 丑的范畴分析框架
  type: framework
  source_chapter: 导论/各时代章
  source_quote: |
    "不管是谈论美还是谈论丑，我们都没有这样的参考，因为那些时代留给我们的只有艺术品。"
  summary: |
    分析「丑」时的三层区分：①丑的东西（物理属性）
    ②对丑的表现（可产生审美愉悦）③丑的观念史（各时代的恐惧投射）。
    三层不可混淆——表现地狱的画可以是美的。
  tags: [ugliness, category, eco]

- id: f02
  title: 恐惧图像学解读法
  type: framework
  source_chapter: 地狱/撒旦/女巫诸章
  source_quote: |
    "中世纪已有巫魔会（Sabbat）之说：女巫在这聚会中不但做法施咒……和魔鬼化身的山羊交媾。"
  summary: |
    图像学三问：①这形象承载哪个时代的恐惧？
    ②恐惧被投射到谁身上（他者化机制）？
    ③图像如何反过来强化恐惧？
    女巫骑扫帚=阳具指涉的案例示范图像的多层读法。
  tags: [iconography, fear, framework]
```

## counter-examples

```yaml
- id: x01
  title: 媚俗的世界替换
  type: counter-example
  source_chapter: 媚俗章
  source_quote: |
    "媚俗的小说并不是'如实'呈现世界，而是将世界呈现成'你希望或害怕它变成的样子'。……媚俗之作的看家本领是专门在效果上下工夫。"
  failure_mechanism: |
    效果至上→情感批发→世界被替换为欲望的镜像→
    观众失去与现实摩擦的机会。
    检测问句：这个作品是在呈现世界还是安慰我？
```

## glossary

```yaml
- id: g01
  term: 媚俗 (kitsch)
  author_definition: 把世界呈现成你希望或害怕它变成的样子；效果至上的情感批发。
  key_distinction: ≠坏艺术——媚俗可以技术娴熟，问题在真诚结构。

- id: g02
  term: 巫魔会 (Sabbat)
  author_definition: 中世纪想象中女巫与魔鬼交欢的聚会——恐惧投射装置。
  key_distinction: ≠历史事实——是对女性他者化的图像建构。

- id: g03
  term: 木乃伊情结
  author_definition: (巴赞语，艾柯引)造型艺术以形式对抗时间的保存冲动。
  key_distinction: ≠死亡崇拜——是以生抗死。
```
