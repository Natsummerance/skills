# 爵士乐风格演变地图

> 蒸馏自 Ted Gioia《如何听爵士》第五章"爵士乐风格的演变"与第四章"起源"、第七章"当代"。把 12 种风格抽成可查的听辨地图。原书章节存于 `knowledge/book-library/distill/ruhetingjazz/chapters/`。

## When to Use

- 用户问"新奥尔良爵士和比波普有什么区别""某个风格该听什么"
- 用户拿到一首曲子想判断它属于哪个风格时期
- 用户想系统听完爵士史、需要风格顺序与代表曲目
- **Don't use for**: 单首曲子深度聆听步骤（去 `jazz-listening-framework`）、找当代活着的大师（去 `jazz-greats-150`）

## 核心命题（I）

1. **每 5 年一场革命**：20 世纪即兴风潮下，5 年差异巨大；1959《几分忧郁》调式革命 vs 1964《精神统一》抛弃调式（ch.5）。
2. **风格可共存但曾内讧**："爵士之战"乐迷分裂阵营；作者主张"网撒得越大越好"（ch.5）。
3. **早期元素贯穿至今**：博尔登将布鲁斯感性+拉格泰姆节奏活力结合铜管，所有当代爵士手都是其传人（ch.4）。
4. **当代四大动力**：全球化、杂糅、专业化、复兴（Nu Jazz）——爵士未死，仍在有机生长（ch.7）。

### 使用步骤
1. 听某曲先判大致年代（书中："你听什么类型的爵士？"）。
2. 对照上表特征锁定风格，再听代表曲目建立听觉锚点。
3. 注意后期风格**共存重叠**（如梅思尼可归融合也可归ECM也可归先锋）——此时放弃贴标签，听"如何超越分类"（ch.5）。
4. ✅完成标准：能向他人解释"为何可以同时爱新奥尔良与比波普"，并说出任一风格的 2 个听辨特征 + 1 位关键人物。

## B — 边界

- **局限**：作者偏美国中心叙事；非裔美国文化根源（ch.4）与亚太/拉美本土爵士（ch.7 承认"亚太不算成熟"）着墨有限。
- "爵士已死"论作者明确反对，但承认经济效益困境（ch.7）——引用时呈现为一家之见。
- 不适用：非爵士流派史、严格音乐学编年。
