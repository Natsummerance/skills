# 当代爵士 150 名家速查

> 蒸馏自 Ted Gioia《如何听爵士》附录"150位爵士名家"与第七章"在当代聆听爵士乐"。把附录的字母名单转化为按乐器/流派可检索的听辨优先级表。原书章节存于 `knowledge/book-library/distill/ruhetingjazz/chapters/`。

## When to Use

- 用户问"现在还有哪些值得听的爵士音乐家""想支持当代爵士但不认识人"
- 用户想按乐器（小号/萨克斯/钢琴/贝斯/鼓/声乐）找当代大师
- 用户要做当代爵士入门、找现场/唱片起点
- **Don't use for**: 已故历史革新家（去 `jazz-history-map` 与 ch.6 的阿姆斯特朗/帕克等）、严格乐理

## 核心命题（I）

1. **附录是"起点不是终点"**：名单按字母排列，收录"事业早期或中期"、年龄最大生于 1960s 的活着的爵士大师；作者鼓励读者自己再添 100 个（附录）。
2. **听当代现场是理想方式**：书中十大动力之一——亲身到现场体验自发性的"宗教仪式"；每种历史爵士"至今仍活跃在演奏台上"（ch.7）。
3. **英雄不再，本土英雄涌现**：全球化让欧洲/亚太本土人才崛起，美国外乐手更自信谈本土爵士（ch.7）。
4. **专业度空前高**：新生代多经学院训练，能轻松演奏 1959 年不敢碰的 7/8 拍（ch.7）。

## E — 速查与检索步骤

### 步骤 1：按乐器检索（从附录抽取的样本，非穷举）
- **小号/短号**：Ambrose Akinmusire、Terence Blanchard、Dave Douglas、Mathias Eick、Ingrid Jensen、Wynton Marsalis、Roy Hargrove、Taylor Ho Bynum
- **萨克斯管**：Melissa Aldana、Ravi Coltrane（约翰·科尔特兰之子）、Kenny Garrett、Steve Lehman、Greg Osby、Donny McCaslin、Branford Marsalis、Grace Kelly
- **钢琴/键盘**：Vijay Iyer、Brad Mehldau、Jason Moran、Ethan Iverson、Cyrus Chestnut、Robert Glasper、John Medeski
- **贝斯**：Christian McBride、Linda Oh、Avishai Cohen、Ben Allison、Larry Grenadier
- **鼓/打击乐**：Brian Blade、Terri Lyne Carrington、Eric Harland、John Hollenbeck、Susie Ibarra、Jeff Ballard
- **吉他**：Rez Abbasi、Mary Halvorson、Julian Lage、Biréli Lagrène、Lionel Loueke、Ben Monder
- **声乐**：Cyrille Aimée、Kurt Elling、Norah Jones、Youn Sun Nah、Sara Gazarek
- **作曲家/编曲**：Darcy James Argue、Miho Hazama、Vince Mendoza、Arturo O'Farrill
- **其他**：Mats Gustafsson（萨克斯）、Regina Carter（小提琴）、Grégoire Maret（口琴）、Nicole Mitchell（长笛）
> 注：附录共 150 人，上表为抽样；完整名单见原书附录文件（letters A~P+ 续）。

### 步骤 2：确定听辨优先级
- **早期大师优先**（书中强调"关注早期/中期"）：Wynton Marsalis（新古典代表）、Brad Mehldau（当代钢琴标杆）、Christian McBride（贝斯锚点）、Vijay Iyer（作者 ch.1 点名"充满矛盾的配合"当代例）。
- **跨风格桥梁**：Ravi Coltrane（承袭又超越父辈）、Robert Glasper（Neo-Soul 跨界）、Brian Blade（作者 ch.1 点名鼓贝斯搭档）。

### 步骤 3：检索动作
1. 用户给乐器 → 查上表给 3~5 个名字 + 代表风格标签。
2. 用户给流派 → 映射到 `jazz-history-map` 风格，再在当代名单找该风格活着的代表（如冷爵士系找 Mehldau、后现代找 Mary Halvorson）。
3. 提醒：附录按字母序非排名；作者明言"轻而易举再塞100个名字"，应鼓励用户自建扩展。
4. ✅完成标准：能按用户乐器/流派给出现役大师清单 + 一句风格注脚，并说明"这是起点非终点"。

## B — 边界

- **局限**：附录是作者 2010s 视角、按字母排列、偏欧美（含少数亚太如 Youn Sun Nah、Linda Oh）；非全球穷举，亚太/拉美本土新星未充分覆盖（ch.7 自承）。
- 名单会随时间老化（部分已中位/晚期）；引用时标注"书中时点"。
- 不适用：历史已故大师检索、非爵士音乐家。
