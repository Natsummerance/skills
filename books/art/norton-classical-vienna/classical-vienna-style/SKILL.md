# 古典风格的诞生 · 维也纳三杰（诺顿断代史·古典卷）

> 蒸馏自菲利普·唐斯《古典音乐——海顿、莫扎特与贝多芬的时代》（孙国忠等译，上海音乐出版社，诺顿断代史丛书）。学术专著：风格分析+社会史双线。原文存 `knowledge/book-library/distill/norton_music/vol1_classical.txt`。

## When to Use

- 用户问"古典主义和巴洛克音乐听感差在哪""海顿莫扎特贝多芬怎么区分"
- 判断一部 18 世纪作品的风格分期
- 理解「奏鸣曲式思维」为何是古典时期的核心成就
- **Don't use for**：浪漫派及以后（用 romantic-music-breakthrough）；断代速查（用 classical-era-map）

## 核心命题（I）

1. **「自然」是新风格的旗帜**：前古典的加利ant风格里，「和声上由Ⅰ（两拍）→Ⅳ（一拍）→Ⅴ（一拍）的完全终止式形成重复的态势……在那个常把自然与简单等同起来的时代，这种风格极易被理解为最'自然的'风格」（第三部分·华丽风格章）（第三部分·华丽风格章，以佩尔戈莱西《女仆作夫人》为例）——简洁周期性乐句取代巴洛克的连续织体。
2. **句法革命：2+2 对称**：「迪特斯多夫交响曲开头引人注目的旋律由三个相等的四小节乐句构成，每一个又都是由2+2的乐汇组成」；a-b-b 三乐句乐段承自 C.P.E.巴赫——古典风格的语法核心是规则乐句的分层组合（交响曲章）。
3. **室内乐即对话**：古典三重奏/四重奏的本质是声部间的交谈——「他也是用小提琴和键盘来对话，而把大提琴作为可用可不用的次要角色」（普雷耶尔段）；这一对话原则在海顿四重奏中达到平衡。
4. **歌剧的戏剧性转向**：莫扎特「加入了很多新的手法，以将正歌剧从习惯性的套路中解放出来，向着现实、真实的人类感情和尖锐的戏剧性转化」——《伊多梅纽》已见格鲁克改革理想的深化（歌剧章）。
5. **公众音乐生活是风格的土壤**：本书专章处理「公众音乐会的兴起」「印刷与出版」「教学文献」——古典风格不是纯美学事件，而是中产阶级音乐消费崛起的制度产物（第二部分）。
6. **三杰定位**：海顿=范式奠基（交响曲/四重奏的构造智慧）、莫扎特=艺术光芒与戏剧神奇（《费加罗》《唐·乔万尼》）、贝多芬=创意与形态整合的极限推进——中译本总序概括为「富于创意的音乐语言与充满智慧的形态整合」（总序）。

## E — 可执行步骤

### 判断古典风格分期（四步听辨）
1. **织体**：连续对位残存（过渡期）还是主调+清晰低音（成熟期）？
2. **乐句**：不规则延伸（早期尝试）还是 4+4 规整周期（成熟标志）？
3. **展开部逻辑**：转调堆砌（早期）还是动机分裂重组的戏剧化推演（海顿式成熟）？
4. **终曲性格**：舞曲回旋的轻快（海顿/莫扎特常态）vs 终曲承担整体论证（贝多芬式突破）。

## B — 边界

- 本书聚焦 1760–1800 德奥核心区，「古典」之外的同时代音乐（法国大革命歌谣、民族传统）仅作背景。
- 「维也纳三杰」叙事是后设经典化；当时最负盛名的实为克莱门蒂、迪特斯多夫等——本书第四章已作还原。
