# 古典音乐断代地图 · 六时期听辨指南

> 蒸馏自《人人都该懂的古典音乐》（朱利安·约翰逊著，中信出版）。本书是断代史导览：把千年西方艺术音乐切成六个可听辨的时期。本 skill 抽取各时期的**听辨特征+代表人物+入门锚点**。原文存 `knowledge/book-library/distill/classical_music_intro/`。

## When to Use

- 用户听到一段古典音乐想知道「这是什么年代的」
- 用户想系统入门古典音乐，要一份按时期的路线图
- 用户问某作曲家属于什么时期/前后继承关系
- **Don't use for**：爵士乐断代（用 jazz-history-map）；具体作品赏析

## 核心命题（I）

1. **「古典音乐」本身是历史产物**：「古典音乐的发展史，就是记谱法的发展史」——它首先是书面的、记谱式的音乐；录音技术反而让边界更模糊（第1章）。
2. **中世纪—文艺复兴（至1600）**：从单旋律圣咏到复调革命——「复调，即许多声部和谐地组合在一起」是西方文化意识的重大突破；记谱法与之相辅相成；帕莱斯特里那为宗教改革时代的集大成者（第2章）。
3. **巴洛克（1600–1750）**：歌剧诞生——「探索人类情感的本质与界限」，音乐语言从对上帝的崇拜转向对自身感受的关注；蒙特威尔第开新纪元，维瓦尔第/巴赫/亨德尔把对位与器乐推到顶点；标题音乐诞生前夜的键盘组曲繁荣（第3章）。
4. **古典主义（1750–1810）**：「音乐的平衡之美」——理性主义的产物；海顿定弦乐四重奏范式，莫扎特歌剧转向普通人的悲喜，贝多芬把独立艺术家形象推向巅峰；启蒙运动使人开始自由创作（第4章）。
5. **浪漫主义（1800–1900）**：情感扩张与个人表达——柏辽兹的标题交响曲、肖邦/李斯特的钢琴诗、瓦格纳的乐剧、勃拉姆斯的绝对音乐立场、柴可夫斯基/德沃夏克的民族之声（第5章）。
6. **现代（1900– ）**：德彪西印象主义→勋伯格无调性/序列主义→斯特拉文斯基新古典主义——象征主义、表现主义等思潮让「好听」不再是唯一标准（第6章）。

## E — 可执行步骤

### 给一首曲子定位时期（四步）
1. **听织体**：单一声部线（中世纪圣咏）/多声部交织（文艺复兴-巴洛克复调）/主调伴奏+旋律歌唱性（古典/浪漫）/不协和解放（现代）。
2. **听节奏与力度**：巴洛克律动恒定；古典乐句方整、强弱对比明确；浪漫弹性速度（rubato）频繁；现代节奏复杂或自由。
3. **听配器**：羽管键琴+小编制=巴洛克；双管编制+弦乐四重奏思维=古典；大乐队+铜管扩张=浪漫后期；打击乐与非常规乐器=现代。
4. **对照锚点曲目**：帕莱斯特里那《马尔切洛斯弥撒》/维瓦尔第《四季》/巴赫《勃兰登堡协奏曲》/莫扎特《第40交响曲》/贝多芬《第五》/肖邦夜曲/德彪西《月光》/斯特拉文斯基《春之祭》。

### 入门路线建议
- 先听有旋律抓手的：维瓦尔第《四季》→ 莫扎特 → 贝多芬 → 肖邦 → 德彪西 → 斯特拉文斯基
- 每个时期挑 1 位深入，比按编年硬啃有效。

## B — 边界

- 六分期是教科书式简化，真实历史有重叠过渡（如巴赫属巴洛克晚期但已含古典萌芽）；本书自陈「古典音乐的跨度非常大」且定义因人而异。
- 本书聚焦西方艺术音乐，不含民族/流行脉络；苏联/东欧线参考 shostakovich-testimony 系 skill。
- 与 jazz-history-map 解耦：结构对标但领域不同，互不指向。
