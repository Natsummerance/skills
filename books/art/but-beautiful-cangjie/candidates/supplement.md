## frameworks（补充）

```yaml
- id: f03
  title: 第二人称独白叙事法
  type: framework
  source_chapter: 钢琴家章（布德·鲍威尔）
  source_quote: |
    "还有这张，摄于1965年。那时你已经一首曲子都弹不了了，钢琴已经变得令人无法忍受，令人精神错乱。你跨坐在一张椅子上……对着相机微笑。"
  summary: |
    戴尔的隐秘技法：整段以「你」称呼传主——
    传记变成招魂式对话。效果：读者被迫成为亲近者。
    用于悼亡写作、人物特稿的视角实验。

- id: f04
  title: 假想相遇场景法
  type: framework
  source_chapter: 比莉·哈乐黛章
  source_quote: |
    "然后来了个肥胖的游客，他犹豫着，看了又看，终于下定决心开口，带着德语口音问她是不是比莉·哈乐黛。——您是这个世纪最伟大的两位歌手之一，他宣称。——哦，只是之一？另一个是谁？——玛丽亚·卡拉斯。你们没在一起演唱真是个悲剧。"
  summary: |
    构造传主与陌生人的假想对话：
    用机智应答（「只是之一？」）呈现人物性格而非罗列成就。
    虚构但有性格依据——与纯虚构的分界在「她真会这么说」。
```

## glossary（补充）

```yaml
- id: g03
  term: 招魂式第二人称
  author_definition: 以「你」称呼已故传主的叙述视角——传记与悼文的杂交。
  key_distinction: ≠普通第二人称小说——对象真实存在过。

- id: g04
  term: 性格依据虚构
  author_definition: 戴尔式虚构的边界——场景可造但应对须符合传主已知性格。
  key_distinction: ≠任意编造——有传记证据约束的想象。
```
