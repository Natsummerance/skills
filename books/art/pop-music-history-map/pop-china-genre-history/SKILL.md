# 中国流行音乐百年断代 · 从时代曲到千禧年

> 蒸馏自尤静波《中国流行音乐简史》（上海音乐出版社套装）。主线：**上海时代曲（1927–49）→ 香港台湾承接 → 内地改革开放后的三波浪潮**。对听中文老歌、理解华语乐坛谱系直接有用。原文存 `knowledge/book-library/distill/pop_music_history/vol2_china.txt`。

## When to Use

- 听到一首中文老歌想知道大概年代与源流
- 用户聊邓丽君/四大天王/校园民歌/西北风，需要谱系定位
- 做华语歌单需要断代框架
- **Don't use for**：欧美曲种本身（用 pop-western-genre-evolution）

## 核心命题（I）

1. **起点：黎锦晖与《毛毛雨》**：「黎明晖也是中国第一首流行歌曲《毛毛雨》的演唱者，于1928年录制了《毛毛雨》的唱片。1927年，她在其父黎锦晖创办的'中华歌舞专修学校'学习」——中国流行音乐诞生于上海，黎派音乐是源头（上海时代曲章）。
2. **时代曲的歌舞片余脉**：五六十年代香港延续上海传统，「著名作曲家姚敏担任作曲，他采用好莱坞式的配乐手法将一批上海时代曲《毛毛雨》《渔光曲》《何日君再来》《玫瑰玫瑰我爱妳》进行重新编配」——时代曲经幕后代唱与电影工业移植香港（港台章）。
3. **台湾的本土化转折**：台语歌「该时期的歌曲曲调很多都受到时代曲的影响……唯独演唱超越了时代曲的风格，一种极具台湾本土特色的歌唱方式开始成为台湾流行歌曲的标志」（台语歌章）；随后 1976–81 民歌运动重塑创作伦理。
4. **1980 年代格局**：「许冠杰、罗文、徐小凤等人在香港歌坛产生重要影响；台湾流行音乐经历了民歌运动之后，也逐渐趋向商业化发展……齐豫、蔡琴、叶佳修、李建复等人已在台湾歌坛享有盛名，《外婆的澎湖湾》《蜗牛与黄鹂》《兰花草》等一批校园歌曲在社会上产生广泛影响」（80年代章）。
5. **90 年代巅峰与符号化**：「1991年，香港歌星依然是台湾乐坛的焦点，'四大天王'的光芒使其他歌手黯然失色」，同期李宗盛式的都市情歌（娃娃《飘洋过海来看你》、优客李林《认错》）代表台湾创作高峰（黄金时期章）。
6. **内地的三波浪潮**：改革开放后港台歌曲涌入 → 「西北风」及本土文化觉醒 → 1990 年代黄金期（通俗唱法登堂入室）——大陆流行音乐在模仿中寻找本土身份。

## E — 可执行步骤

### 判断中文老歌的年代（四步）
1. **听编曲语言**：爵士小乐队+舞曲节奏 → 上海时代曲或其香港延伸（1930s–60s）；电吉他+民谣吉他 → 民歌运动后（1976+）；电子鼓机+合成器 → 80 年代中后期。
2. **辨演唱语汇**：委婉苦情的时代曲腔 / 校园民歌的清新直白 / 西北风的秦腔高腔 / 都市情歌的口语叙事。
3. **查地理标签**：上海→香港→台湾→内地，每站有标志厂牌与人物。
4. **锚点对照**：《毛毛雨》(1927) → 《何日君再来》(1937) → 《月亮代表我的心》邓丽君版(1977) → 《外婆的澎湖湾》(1980) → 《潇洒走一回》(1991)。
