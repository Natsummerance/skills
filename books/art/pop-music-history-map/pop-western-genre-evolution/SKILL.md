# 欧美流行乐种演化地图

> 蒸馏自尤静波《欧美流行音乐简史》（上海音乐出版社·流行音乐简史套装，教材）。体系化强但深度有限——胜在谱系清晰：每个曲种的来龙去脉一页讲完。原文存 `knowledge/book-library/distill/pop_music_history/vol1_western.txt`。

## When to Use

- 用户问"R&B 和 soul 有什么区别""摇滚是从哪来的"
- 听到一首流行歌想判断其曲种与源流
- 做歌单/乐评需要曲种演化的准确表述
- **Don't use for**：爵士深读（用 jazz-history-map）；华语脉络（用 pop-china-genre-history）

## 核心命题（I）

1. **四大文化特征**：「因其特殊的历史、地域及文化背景，在发展中逐渐形成了都市化、商业化、大众化、电声化特征」；其中「流行音乐是都市中的民间音乐，它的发展以都市为中心」（绪论）。
2. **二战前的美国格局**：「至第二次世界大战结束之前，世界上的流行音乐主要集中在美国，以黑人的布鲁斯，白人的叮砰巷音乐（Tin Pan Alley）、乡村音乐以及由黑人文化和白人文化融合而成的爵士乐为主。其中爵士乐是该时期流行音乐的主要代表」（绪论）。
3. **两大转折点**：「二十世纪流行音乐的发展主要有两个转折点，分别是十九世纪末二十世纪初爵士乐的诞生和1950年代摇滚乐的出现。爵士乐和摇滚乐既是美国音乐的代表，也是流行音乐的两大标」（绪论）。
4. **1980 年代后的转向**：「以美国黑人为主的说唱乐（Rap）和嘻哈乐（Hip-Hop）得到发展并成为新时代黑人音乐的代表……创新与融合在此时已成为世界流行音乐发展的重要方向」（绪论）。
5. **演化主链**：非洲音乐遗产 → 布鲁斯（乡村/古典/城市/R&B 四阶段）→ 爵士 ↔ 叮砰巷 → 摇滚（吸收乡村+R&B）→ 灵魂/放克 → 迪斯科 → 嘻哈。每一步都是黑人音乐资源被商业化再包装的循环。

## E — 可执行步骤

### 判断一首歌的曲种源流（四问）
1. **节奏组**：摇摆律动（爵士系）/直拍 backbeat（摇滚系）/机械四踩（迪斯科-电子系）/采样循环（嘻哈系）？
2. **声乐传统**：蓝调音阶与呼应对唱（布鲁斯-灵魂系）/白人民谣叙事（乡村系）/旋律工业流水线（叮砰巷-流行系）？
3. **配器时代感**：原声乐队/电声乐队/合成器/采样机？
4. **回溯定位**：沿 布鲁斯→爵士→摇滚→灵魂→电子→嘻哈 主链找最近祖先。

## B — 边界

- 教材性质：体系清晰但个案深度有限，重要艺术家着墨平均，争议性论断较少。
- 断代截至成书（2015 前后），流媒体时代的曲种融合未覆盖。
