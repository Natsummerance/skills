```yaml
- id: f03
  title: 协奏曲对话框架
  type: framework
  source_chapter: 协奏曲章（莫扎特钢琴协奏曲）
  source_quote: |
    "他通常会在同一个乐章中把不同的材料组合在一起，然后任其自由发展，就像歌剧中众多的角色同台登场一样。音乐家对公开的音乐语言与私人情感之间的平衡把握，在古典钢琴协奏曲中表现得尤为明显。"
  summary: |
    听协奏曲的钥匙：独奏与乐队的对话戏剧。
    三步：①辨认角色登场（独奏vs乐队的主题交替）
    ②追踪对话张力（炫技段=独白，全奏=合议）
    ③听公开语言与私人情感的平衡。
  tags: [concerto, dialogue, listening]

- id: f04
  title: 处境-风格对应法
  type: framework
  source_chapter: 巴赫年表章
  source_quote: |
    "三个时期不同的处境造就了他不同的音乐风格。他的许多管风琴和键盘器乐都出自第一个时期，室内合唱音乐则集中于第二个时期，而绝大多数的康塔塔诞生于第三个时期。"
  summary: |
    用「职位年表」解释风格分期：魏玛(管风琴)→科腾(室内乐)→莱比锡(康塔塔)。
    作曲家写什么首先由其岗位决定——先查他当时在哪任职、为谁写作，
    再谈个人灵感。用于作曲家研究、曲目语境理解。

- id: f05
  title: 惯例依赖提示法
  type: framework
  source_chapter: 歌剧章
  source_quote: |
    "喜歌剧的流行也依赖观众对其惯例的熟悉程度……所谓惯例包括模式化的角色和情景设定……讲述故事的常用音乐手法，即咏叹调和宣叙调的先后顺序；以及与角色类型相关的音乐风格和声音特点。"
  source_quote_note: 18世纪观众并不习惯安静坐着欣赏歌剧——惯例是欣赏的前提。
  summary: |
    「听不懂」的另一半原因是不懂惯例：角色套路/咏叹调宣叙调顺序/
    声音类型编码（粗犷=仆人）。入门三步：①列出该体裁惯例清单
    ②听时对照惯例识别③惯例熟后自然超越。
```

  type: case
  source_chapter: 巴赫章
  source_quote: |
    "1717年：在魏玛宫廷担任管风琴师；1717年至1723年：在科腾宫廷的利奥波德亲王麾下任乐队指挥；1723年至1750年：出任圣托马斯教堂乐监以及莱比锡市音乐指挥。"
  summary: |
    绑定f04处境-风格法：巴赫不是想写什么写什么，
    而是岗位要什么写什么——天才与制度的合作。

## glossary（补充）

```yaml
- id: g04
  term: 咏叹调/宣叙调
  author_definition: 歌剧的两种唱段——咏叹调抒情展示，宣叙调推进剧情。
  key_distinction: ≠艺术歌曲——功能服务于戏剧行进。

- id: g05
  term: 全奏/独奏交替
  author_definition: 协奏曲中乐队全体与独奏者的轮流陈述结构。
  key_distinction: ≠伴奏关系——是对话双方而非主从。
```
