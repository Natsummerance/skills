# 按心境选爵士 · 场景配乐逻辑

> 蒸馏自杰夫·戴尔《然而，很美：爵士乐之书》。把书中七位乐手各自弥漫的「房间气氛」抽成一张可即查的选乐表。原书 11.4 万字存 `knowledge/book-library/library/艺术/音乐/然而，很美…epub`。

## When to Use

- 用户说「**我现在__（孤独/失眠/下雨/开车/想哭/想一个人待着），放点什么爵士**」
- 用户要为**某个场景**（深夜阳台、雨天咖啡馆、长途夜车）配一段爵士背景乐
- 用户想从「氛围」而非「流派/乐手名气」出发挑唱片
- **Don't use for**：学乐器、练耳、分析曲式（技术维度技能的事）；本 skill 只做「心情→乐手」的映射，不教听

## 核心命题（I — 选乐逻辑）

1. **每个乐手是一个「房间」**：戴尔把书比作一座私人爵士乐博物馆，「里面只有七个不大的房间，每个房间都属于一位爵士音乐家……每个房间都弥漫着自己独特的气氛：有的温柔，有的迷幻，有的忧伤，有的狂暴」。
2. **选乐 = 选房间**：你不是挑一首曲子，是挑一个能容下此刻心境的空间。
3. **书是「感受的结果，不是研究的结果」**（戴尔：「什么资格都没有，我只是爱听」）。本 skill 同样以「此刻我想被什么包围」为唯一标准。

## E — 可执行选乐步骤

激活本 skill 后，按以下流程给用户一张选乐单：

### 步骤 1：让用户点出一种心境/场景（二选一即可）
孤独 / 深夜清醒 / 雨天 / 长途夜车 / 想哭又不想哭 / 想被温柔包裹 / 需要狂暴的能量

### 步骤 2：映射到对应「房间」（书中七位 + 串场公爵）
| 心境/场景 | 对应乐手 | 书中气氛依据 |
|---|---|---|
| 深夜独处、缩小消失感 | **莱斯特·扬** | 旅馆窗边「风景被他的呼吸模糊」，霓虹绿光里「他正在缩小、枯萎、消失」；萨克斯「像微风在寻找风」 |
| 想被温柔包裹（但带着空） | **切特·贝克** | 阿姆斯特丹「走过像家一样的古董店，走过像古董店一样的家」，小号「纤弱柔美，几乎显得女人气」 |
| 忧伤、想哭、布鲁斯 | **本·韦伯斯特** | 「他喜爱柔美的情歌，伤感的曲调……无论吹得多柔软，里面总潜伏着低沉的咆哮」；《感伤时分》 |
| 狂暴、需要能量宣泄 | **查尔斯·明格斯** | 「全速行进的乐队就像几只飞驰的猎豹正在被一头大象追击」；《直立猿人》《唤猪布鲁斯》 |
| 迷幻、疏离、照不见自己 | **瑟隆尼斯·蒙克** | 蒙克造的桥「建在一片空无之上」；钢琴「八十八个，够呛」 |
| 破碎后仍要笑、悲剧天才 | **巴德·鲍威尔** | 妻子「我耳朵里全是眼泪」；「巴德·鲍威尔，巴德·鲍威尔」的的呢喃 |
| 海港、水边、漂泊 | **亚特·派伯** | 哥本哈根海港吹萨克斯，「大海是他完美的听众」；布鲁斯的忧伤「体现在一声雾号里」 |
| 长途夜车、公路沉思 | **艾灵顿公爵（串场）** | 「就像汽车是台扫雪机，把黑暗铲到一边，清出一条光的道路」；「公路就是他的家」 |

### 步骤 3：给一句「为什么是TA」的书中原句
不要只给名字。附上步骤 2 表里那句书中场景，让推荐有体温。
- 例：「深夜失眠 → 放莱斯特·扬。因为他『正在缩小、枯萎、消失』，而他的萨克斯『像微风在寻找风』——适合一个人缩在窗边。」

### 步骤 4：留一个「然而，很美」的出口
若用户是「想哭」，用书名公式收尾：痛是被允许的，「然而，很美。就像亲吻眼泪。」

## B — 边界

- 本 skill 是**审美/氛围向**选乐，基于戴尔书中的主观感受，不是客观唱片指南；具体曲目版本需另行确认。
- 七位乐手是书中人物，不等于「他们只适合这一心境」——映射是入口不是定论。
- 与 jazz-melancholy-aesthetics 互补：那本解释「为什么忧伤动人」，本 skill 把它变成「此刻放哪张」。
