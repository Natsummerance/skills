# 学术写作 · 论证逻辑工具

> 蒸馏自学术写作指导书第6章《论证的逻辑性》。本 skill 管**论证结构**——数据能否推出结论、链条是否断裂；不管写作姿态与语言风格（用 `academic-writing-reader-mind`），也不管句子级语言修改（用 `academic-writing-language`）。原文存 `knowledge/book-library/distill/xueshu_xiezuo/`。

## When to Use

- 审稿或自查：判断「这个结论是否被数据支持」「这段论证哪里有漏洞」
- 回复审稿人对备择假设的质疑，或在讨论部分主动呈现并排除备择假设
- 评估媒体转述的研究结论（相关→因果？取样偏差？）
- **Don't use for**：语言是否简洁精确、读者姿态问题（用 `academic-writing-reader-mind`）；具体措辞的精确化操作（用 `academic-writing-language`）

## 核心命题

1. **逻辑是思维方式而非语言问题**：「论证的逻辑性说到底不是关于语言的问题，而是思维方式的问题」（第6章）。学术论文两类高频病：一类是「数据不支持结论」，另一类是「论证过程中有漏洞」（第6章）。
2. **论据必须真的指向结论**：用「80%的学霸都午睡」论证午睡有益站不住脚——若「100%的学渣都午睡」呢？（第6章）。用剖腹产死亡率更高论证顺产更好，忽略了两群体取样不同（剖腹产样本多有手术指征）（第6章）。
3. **相关 ≠ 因果**：巧克力消耗多的国家诺奖得主多≠吃巧克力变聪明——可能是经济水平影响教育再影响科研支持；且统计的是国家而非个人（第6章，Franz & Messerli, 2012 例）。血型与新冠易感性研究只有相关性结果，「还很难证明」因果（第6章）。
4. **取样偏差是最常见的备择假设**：父亲年龄大孩子孤独症概率高7倍→「生娃趁早」是错的，晚育者本身可能有遗传相关特质（第6章）；母乳喂养优势在控制经济条件后消失（第6章）；线上问卷「100%能上网课」是因为填不了问卷的人根本没机会作答（第6章）。
5. **备择假设的系统性排除才产生说服力**：「当所有备择假设都被排除时，结论成立的可能性就大大增加了」；若论文讨论部分「能够呈现出各种备择假设，并对其一一进行批驳，那么这样的文章无疑是非常有说服力的」（第6章）。随机双盲实验正是靠设计排除期待效应等备择假设（第6章）。
6. **论证链条不能跳步**：学生写「我们还设置了闭眼条件……因为闭眼可以消除说话者眼部的威胁信息」，缺了「为什么眼部威胁信息重要」一环，链条连不起来（第6章）；「因为他们注视嘴部多，所以注视嘴部的时间不能预测视听言语整合」这类因果「经不起推敲」（第6章）。前后句都对不等于因果关系成立，「这里需要补充文献把这个逻辑补上」（第6章）。
7. **归谬法是驳论利器**：张文宏驳「不能复工」——先假设对方观点成立，引出其结果（生活停摆死的人比病毒致死更多），论证其荒谬，最后给出带防护前提的替代方案（第6章）。
8. **训练途径**：对最经典的研究也刻意提备择假设来锻炼逻辑（如「梦发生在REM阶段」vs「REM阶段的梦更容易被记住」（第6章））；推荐《这才是心理学》《你以为你以为的就是你以为的吗》与案件推理公众号「没药花园」（第1章、第6章）。

## E — 可执行步骤

### 流程 A：数据-结论审查四问
1. 数据真的支持结论吗？换成对立数据，原论证是否同样成立？（学霸午睡检验）
2. 两组比较的取样是否同质？有无手术指征式的隐性选择差异？
3. 相关结果背后有哪些备择假设？至少列3个（第三变量、反向因果、取样偏差、生态学谬误）。
4. 统计单元与结论单元一致吗？（国家层面数据推个人结论=错）

### 流程 B：论证链完整性检查
1. 把段落拆成命题序列：P1→P2→…→C。
2. 逐个衔接处问：从 P(n) 到 P(n+1) 缺了什么前提？缺文献支撑还是缺定义？
3. 每个因果断言追问：前后都对，但为什么必然导致？（发展语言→多看嘴部？需补文献）
4. 解释不一致结果时检查：我的解释是在消解不一致，还是在给对手送筹码？

### 流程 C：讨论部分·备择假设批驳写法
1. 列出所有合理备择假设（含取样偏差、暴露机会差异、测量方式差异）。
2. 对每个假设逐一分析：若它为真会观察到什么？实际观察到了什么？
3. 全部排除后才下结论；无法排除的诚实写入局限性。
4. 驳斥他人观点时可用归谬法：接受对方前提→推出不可接受的后果→提出带前提条件的己方方案。

### 流程 D：常见漏洞速查表
- 相关当因果（巧克力-诺奖、血型-新冠）
- 取样偏差（晚育父亲、母乳家庭、网课问卷、「没来的请举手」）
- 幸存者偏差（幸存战机弹痕多就加固弹痕处——被打落的部分没样本，第6章练习）
- 单一归因（孤独症率上升怪母乳减少——三十年间变化的东西多了，第6章）
- 基线混淆（古人癌症少因寿命短没活到发病，第6章）

## B — 边界

- 本 skill 是**论证结构层**：只回答「推理是否成立」。行文姿态、简洁精确的服务意识属 `academic-writing-reader-mind`；词句落地属 `academic-writing-language`。三层互斥互补。
- 书中案例多为心理学/流行病学语境；形式逻辑（三段论）本身不在本 skill 范围内——本书作者也认为三段论式教学「深奥又枯燥」。
- 备择假设列举无上限，实践中按「审稿人最可能提的」排序处理，避免无限怀疑主义。
- 不适用于：数学证明的形式化验证；纯修辞说服（那是创意/演讲领域）。
