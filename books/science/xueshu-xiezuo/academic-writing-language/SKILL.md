# 学术写作 · 语言层修改清单

> 蒸馏自学术写作教材第4章「语言的精确性」、第5章「文章的质量」、第7章「语言流畅性：句子结构」、第8章「段落」。不是书摘，而是一套按词→句→段推进的语言层修改自查清单。原文存 `knowledge/book-library/distill/xueshu_xiezuo/`。

## When to Use

- 用户交来论文/文稿要求改语言、润色、「看看有没有表达不清的地方」
- 用户自检英文/中文学术稿件的歧义、模糊、啰嗦问题
- 用户抱怨「读起来不通顺」「句子之间没衔接」审稿人说 “writing needs improvement”
- **Don't use for**：论证逻辑与故事线（用 `academic-writing-argument-logic`）；读者心理预期总纲（用 `academic-writing-reader-mind`）；格式/APA细则（本清单只收录与语言直接相关的部分）

## 核心命题（I）

1. **精确是底线，简洁是良心**：「如果说精确是作者的底线，那么可以说简洁是作者的良心」，且「语言的精确要优先于语言的优美（clarity over elegance）。任何时候，精确都是第一位的」（第4章）。学术语言的目标是「让读者对作者的表述只有一种理解方式」（第4章）。
2. **不精确来自两类源头**：「不精准描述的产生一部分来自语言本身（多义字/词和歧义句）产生的歧义；一部分来自语言的使用，比如没有精确地定义术语、词的修饰范围不明、代词指代不明等」（第4章）。
3. **修辞手法是禁区**：「在创意写作中学到的修辞手法或者技巧，最好不要用到学术写作中」——双关如鲁迅笔下「不干不净」表面指卫生实指败俗，这类「高级的用法在学术写作里几乎是看不到的，我们不需要读者去猜我们隐含的意思」（第4章）。
4. **质量是文章的颜值**：「我这里说的质量不好，主要指的是‘品相不佳’，即低级错误太多。这些低级错误包括拼写错误（typo）、语法错误、格式错误、语言的倾向性问题、细节把控不佳等」（第5章）。「如果有很多低级错误，主编第一眼看过去可能就对你的研究产生了怀疑」（第5章）。
5. **结构决定85%的句意**：「用词只决定了句子意思的15%，而结构决定了句子意思的85%」（戈朋《结构感》，第7章）。变换结构即可改变语气正负：四条审稿意见中「although」从句弱化其引导内容，「所以四条意见中第三条是最正面的，而第一条是最负面的」（第7章）。
6. **连贯靠意义而非连词**：「我认为好的连贯性是不需要（或者应该尽量少用）连词的，而应该在意义上连贯」；经典范例段落从第一句的 worry 到第二句的 worries、从宾语到主语环环相扣（第7、8章）。硬凑连词是「典型的懒得理顺文章的逻辑关系，强行用连词来连接的做法」（第7章）。
7. **流畅性=给读者信号**：「降速、打信号灯就是你给读者的提示（signal），告诉他们：我要转弯了。写作也是一样，需要这样的提示，读者才不会晕」（第7章）。不流畅的文章让读者像坐晕车——离散句堆砌即「前言不搭后语」（第7章）。
8. **段落三件套与开门见山**：典型段落由「主题句（topic sentence）、支撑句（supporting sentences）以及结论句（concluding sentences）」构成（第8章）；中文习惯「拐弯抹角、百转千回，最后才提出观点」，而「英文的思维方式是越早亮出观点越好，最好是开门见山」（第8章）。
9. **跳板句负责跨段过渡**：「从上一段跳到下一段，需要一个过渡……告诉读者下一段要讲什么，为下一段的内容做好铺垫」（第8章）；引用文献须先梳理成「结论驱动（conclusion driven）的段落」，否则是把梳理工作丢给读者的「文献驱动（literature driven）写法」（第8章）。

## E — 可执行步骤

以下四张清单按「词→句内→句间→段间」顺序执行；每条都可独立判 ✅/❌，❌ 即为待改点。

### 清单A：词层——歧义词与用词精确（第4、5章）

1. [ ] 全文搜多义词与分词敏感处（中文无空格尤甚）：「最著名的例子就是“武汉市长江大桥”，可以读成“武汉市/长江大桥”，也可以读成“武汉市长/江大桥”」（第4章）——切分只有一种读法才通过。
2. [ ] 近义词逐一查证再选用：连母语小孩都知「Probably means yes. Possibly means no」；「finish」与「complete」看似同义实则相反（第4章）。方法：「查英英字典，或者英汉双语字典」＋「在语料库中寻找各种意义相近的词，然后看上下文的语境」（第4章）。
3. [ ] 排查文化负载词误用：答辩PPT结尾「感谢聆听」不准确，“聆听”其实暗含晚辈听长辈教诲的意义（第4章）。
4. [ ] 删掉模糊量化修辞：「或多或少的相关」必须替换为分级描述，如 Evans 建议 .20-.39 为 weak、.60-.79 为 strong（第4章）。
5. [ ] 检查形容词与名词的正负搭配：「great impairment」错在impairment 是个负面的词，great 是相对正面的」，应改 severe / profound / fundamental（第5章）。
6. [ ] 删语义重复：“stimuli were repeated again”中 repeat 已含 again；「compare the difference between the two groups」应改为 compare the two groups 或 examine the difference（第5章）。
7. [ ] 术语全篇统一：同一概念只许一种写法——反面案例一篇文章混用「self-reference/self reference/self-referential」等五种表述，「在这些地方重复没关系，而且写学术文章也不是炫耀词汇量的时候」（第5章）。
8. [ ] 慎用低频缩写：「对于只出现一两次的缩写，因为不容易记住，会造成记忆的负担，所以建议写全称」（第4章）。
9. [ ] 描述他人工作不带评判词：禁 weakness / advanced / regretfully 这类「潜台词就是别人没做好」的词（第8章）。

### 清单B：句层——语义模糊六查（第4、5章）

1. [ ] **术语有定义吗**：新术语出现后「马上给出精准的释义，并举例说明」；反例「compromised sensitivity」是「自创的表述方式，也没有说明与什么比较」（第4章）。勿假设读者知识储备与你相同（第4章）。
2. [ ] **利伯恩配对五项**（第4章）：新概念↔解释、缩写↔全称、介词↔指代名词、动词↔宾语、背景↔所解释内容——两两相邻出现。
3. [ ] **different/differ 系列逐个核对**：「differed in their response time」没说是快还是慢，应写明 shorter；「different from the 5-year-old children」存在两种解读，须写明另一种孩子是反转还是无差异（第4章）。
4. [ ] **限定词范围唯一**：「十几个学校的老师」歧义——修饰学校还是老师？英文「only in the open-eyes condition」应改为「in the open-eyes condition but not in the closed-eyes condition」（第4章）。
5. [ ] **代词指代清晰**：「通常指代距离最近的一个词」——反例中 their 实际指代远处的 abnormal asynchronous propagations，解法是「把代词换成所要指代的名词」（第4章）；「It was consistent with…」的 it 应改为 This finding 或合并句子（第4章）。
6. [ ] **形式主语=实际主语**：「To examine…, forty-five participants were divided」中 examine 的主语应是 we 不是 participants，改「we divided forty-five participants evenly into three groups」（第5章）；同理 run experiments 的主语是作者（第5章）。
7. [ ] **多分句主语统一**：三个分句用了三个主语 the ability/the time和they」，应统一为一个主语或改写（第5章）。
8. [ ] **长句拆短**：「一般长度在四行以上的句子就要谨慎使用了」，一句话变两句、删掉不需要的细节（第4章）；主谓之间不得插入长定语从句阻隔（第7章）。
9. [ ] **删冗余框架句**：任何以 “previous research has found that” 或者 “×××were reported” 作为开头的句子都可以省略这两种表述」（第4章）；重复陈述第二三句复述第一句时整句删除（第4章）。
10. [ ] **去 there be 与被动**：常见的 “there be” 句型“我不太推荐使用”；APA 建议尽量不用被动语态，「50 participants were recruited」改「We recruited 50 participants」——「不要怕用I和we」（第4章）。

### 清单C：句间——戈朋结构五问（第7章）

对每个句子依次回答（源自修改现场三问：你这句话想表达的主要意思是什么？这句话两个分句之间的关系是什么？这句话和上一句话的关系是什么？）：

1. [ ] **动作落在强动词上吗**：动作应由动词而非名词表达——「The recruitment of 40 participants was through…」不如「We recruited 40 participants」；弱动词 be/exist/become 出现时真动作被挪走（第7章）。例外仅在需委婉传递坏消息时（如拒稿信用名词化弱化 rejection，第7章）。
2. [ ] **句子讲的是最先出现者的事吗**：读者默认句子讲述最先出现的人/物——真正主语是 his wife 时不要以 Although he is a nice guy 开头；戈朋教授不建议使用以 although 作为开头的句子（第7章）。
3. [ ] **谓语紧跟主语吗**：「如果主语后面跟了过多无关紧要的细节，就会影响找谓语的过程」——反例一句中 data 的谓语 are 被长插入语隔开数行（第7章）。
4. [ ] **重要信息在句末着重点吗**：「要把重要的信息放到句子后半部分」——着重点（stress point）在句子后半部，决定整句听起来正面还是负面（第7章）。
5. [ ] **句首接住了上句句尾吗**：用「Subject1+Verb1+SP1. Subject2+Verb2+SP2」检查——Subject2 应与 SP1 意义相联；反例「从we found that跳到two previous studies，需要读者花时间厘清」，补 This finding is 作桥（第7章）。
6. [ ] **概念切换有铺垫吗**：新概念（如 working memory）首次出现须立即解释；跳主题前先想「从一个概念转换到另一个概念时是不是足够顺畅」（第7章）。

### 清单D：段落层——结构与跳板句（第8章）

1. [ ] **每段有主题句吗**：主题句「提示了段落的主要内容」，读者只读各段主题句即可了解全文大意；缺主题句的段落「各个句子之间的关系比较离散」（第8章）。
2. [ ] **一段一个话题（一致性）**：「如果有句子不属于这个话题，最好删除。如果一个段落有两个话题，最好分成两个段落来写」（第8章）。
3. [ ] **关键词串联（连贯性）**：靠重复关键词实现环环相扣；同时检查代词统一——指代被试时一会儿用 they，一会儿用 he要修（第8章）。
4. [ ] **段尾装跳板句**：四种学术可用过渡（第8章）：
   - 观点过渡：段尾写「但是这个假设/观点并没有获得所有证据的支持，也有研究者认为……」
   - 问题过渡：段尾抛出遗留问题引出下段
   - 事实过渡：从宽领域收束到一个有意思的点（「其中，孤独症个体对眼睛的回避现象引起了学界的广泛关注」）
   - 实验间过渡：前言末段交代共几个实验、各自做什么；每个实验结果后总结未解决问题以引出下一实验
5. [ ] **列举必须写完**：「不能光有First没有后文」，同理 on the one hand 必配 on the other hand（第8、5章）。
6. [ ] **引用是结论驱动吗**：禁止「孔子有云……孟子有云……孙子又有云」式罗列；「先把文献梳理好，厘清文献之间的关系，找到它们的共同点和不同点，然后写出结论驱动的段落」（第8章）；大段直接引用是偷懒，仅权威背书、批评靶子、文言原文、无法改写四种情况例外（第8章）。
7. [ ] **组织顺序明确**：方法用时间顺序、论证目标用逻辑顺序、争议用对立观点双面呈现——「两个方面的证据都提到」（第8章）。

## B — 边界

- 本 skill 只管**语言层**：词—句—段的精确性与流畅性。故事线与谋篇布局（第9章）、论证逻辑（第6章）不在范围内——见 `academic-writing-argument-logic`；读者心理模型总纲见 `academic-writing-reader-mind`。
- 五问/三问清单是启发法而非语法规则：文学创作、法律文本有意违反（主谓分隔制造悬念），但「学术写作的目的永远是让人看得懂」（第7章）。
- 结构五则可能显死板：「严格遵循这种写法好像也比较死板」，在不影响主要意思前提下尽量调整即可（第7章）。
- 原书语境为心理学英文论文写作（APA 传统）；中文写作可迁移歧义/模糊/段落原则，被动语态、冠词等条目仅适用英文。
- 语言编辑公司只能处理低级错误层面，「语言、段落结构、谋篇布局甚至句子的写法，还是要自己把握」（第5章）。
