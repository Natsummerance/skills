- id: f01
  title: 历史意见/时代意见区分框架
  type: framework
  source_chapter: 总论
  source_quote: |
    "历史意见，指的是在那制度实施时代的人们所切身感受而发出的意见。这些意见，比较真实而客观。……时代意见并非是全不合真理，但我们不该单凭时代意见来抹杀已往的历史意见。"
  summary: |
    评价古代制度前先分清两种意见：
    历史意见=制度实施时当事人的切身反映（更真实客观）
    时代意见=后人凭自身环境需要的批评（不可抹杀前者但非唯一依据）。
    操作化四步：①还原人事（该制度解决当时什么问题）
    ②采集历史意见（找当时人如陆贽论两税的批评）
    ③对照时代意见（标注自己的现代预设）
    ④双向校准后下判断。
    适用：gaokao历史评析题/网络历史争论/制度比较研究。
  tags: [historiography, methodology, framework]

- id: f02
  title: 制度分析四线框架
  type: framework
  source_chapter: 总论+各朝篇
  source_quote: |
    "我们讨论一项制度，固然应该重视其时代性，同时又该重视其地域性。推扩而言，我们该重视其国别性。"
  summary: |
    每朝制度拆四条线分别梳理：
    ①政府组织（皇权/相权划分与制衡结构）
    ②考试选举（察举→九品中正→科举的人才筛选演变）
    ③经济赋税（租庸调→两税→一条鞭的税制逻辑）
    ④兵役国防（禁军/府兵/卫所的兵制循环）。
    四线交叉才能定位一项制度的真实位置。
    适用：任何断代制度的全景速查。
  tags: [institutions, four-lines, framework]

- id: f03
  title: 制度生命力与僵化诊断
  type: framework
  source_chapter: 总论·第四点
  source_quote: |
    "政治制度是现实的，每一制度，必须针对现实，时时刻刻求其能变动适应……但到后来，因施行的时间空间关系都不同了，而还是照样沿用，遂终于出了大毛病。"
  summary: |
    制度的生命来自对现实的适应；沿用过时的制度=制度变法术。
    九品中正制创设时是苦心救弊，沿用后变成拥护门第——
    同一制度在不同时空产出完全不同的结果。
    检验问句：该制度现在面对的现实还和创设时一样吗？
    适用：组织流程老化诊断/政策延续性评估。
  tags: [institutional-decay, adaptation, diagnostic]

- id: f04
  title: 皇权相权二元结构框架
  type: framework
  source_chapter: 汉代篇·唐代篇
  source_quote: |
    "若论汉、唐、宋诸代，中央政府的组织，皇权相权是划分的，其间比重纵有不同，但总不能说一切由皇帝专制。到了明太祖洪武十三年……从此就废止宰相，不再设立。"
  summary: |
    传统中国中央政府的权力结构不是「皇帝独裁」一句话能概括：
    汉/唐/宋有皇权相权划分（唐代门下省涂归封驳权即相权制衡实例），
    明清废相才是特例而非通例。
    分析古代政制先问：这个朝代的相权在哪？被谁分割？
  tags: [emperor-chancellor, power-structure, framework]

- id: f05
  title: 制度vs法术判准
  type: framework
  source_chapter: 明代篇
  source_quote: |
    "不能说皇帝私下决定了，不再给政府行政长官预闻就可办。这绝不能说是一种制度，也不能说它是习惯法，只该说它是法术。为什么？因为这是纯粹出之于私心的。"
  summary: |
    制度=公开的、为公的、可预期的规则；法术=出于私心、不可告人、随机应变的手段。
    钱穆用此判准区分明清特例与传统常态。
    检验问句：这项做法是公开规则还是私下操纵？
  tags: [institution-vs-tactic, public-private, framework]
