# 五路 Extractor 合并产出 — 《第二性》I

## frameworks

```yaml
- id: f01
  title: 他者化机制分析框架
  type: framework
  source_chapter: 导言/历史章
  source_quote: |
    "态度要求人人平等，从现在直至未来都拒绝任何一类人成为客体或偶像……然而，很少男人完全符合自己选择做的士兵、战斗者的形象。"
  summary: |
    他者化的运作分析：①主体群体自我确立（士兵/战斗者形象）
    ②将另一群体界定为客体或偶像③客体地位反过来巩固主体认同。
    检测三问：谁在定义？谁被定义？定义让谁受益？
    可迁移至一切群体不平等分析。
  tags: [othering, mechanism, beauvoir]

- id: f02
  title: 处境vs本质辨析框架
  type: framework
  source_chapter: 命运章（三重批判）
  source_quote: |
    "如今我们必须明白，这种处境如何延续下来，世世代代发展下去。"
  summary: |
    波伏瓦方法论核心：把「天生如此」改写为「处境如此」。
    操作：①识别本质主义断言②追溯其形成的具体处境
    ③评估处境改变的可能性。三重批判示范：
    生物学/精神分析/唯物主义的解释各有洞见但皆非命运。
  tags: [situation-vs-essence, method]
```

## cases

```yaml
- id: c01
  title: 原始群体中的女人命运
  type: case
  source_chapter: 历史章
  source_quote: |
    "我们刚才看到，在原始群体中，女人的命运是十分艰难的；在雌性动物身上，生育作用是自然而然地受到限制的。"
  summary: |
    绑定方法论：处境vs本质。生育的生理事实与
    「艰难的命运」之间隔着社会安排——波伏瓦区分
    生理事实与社会处境的关键示范。
- id: c02
  title: 士兵形象与德国士兵的信
  type: case
  source_chapter: 导言
  source_quote: |
    "我读过德国士兵写给法国妓女的信，信中不顾纳粹主义，多愁善感的习俗显得天真活泼。"
  summary: |
    绑定方法论：他者化机制。意识形态宣称与私人情感的
    裂缝——他者化从不彻底，人总能溢出范畴。
```

## glossary

```yaml
- id: g01
  term: 第二性
  author_definition: 相对于男性主体的次要存在位置——由历史形成而非天性注定。
  key_distinction: ≠次等品性的断言——是对不平等位置的描述。

- id: g02
  term: 他者 (l'Autre)
  author_definition: 被主体界定为非主体的存在范畴。
  key_distinction: ≠敌人——他者可以是偶像化的（圣母/荡妇二分）。

- id: g03
  term: 处境
  author_definition: 自由展开的具体条件总和——身体、历史、社会位置。
  key_distinction: ≠环境决定论——处境限制自由但不取消自由。
```
