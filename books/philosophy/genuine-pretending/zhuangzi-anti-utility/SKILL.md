# 反功利主义 · 非工具化生活哲学

> 蒸馏自《游心之路》（梅勒、德安博）。本书把《庄子》的「无用之用」「上德不德」读作对儒家「双层一致/真诚机制」及一切功利化、偶像化价值建构的批判——卓越若被真诚承诺便会引向毁灭。原书约 17 万字已存 `distill_out_zhuangzi/_raw/full.txt`。

## When to Use

- 用户被「要有用/要出成果/要效率」绑架，问「做无用的事有意义吗」
- 用户因「不够成功/没价值」自我攻击
- 用户把技能/美德真诚承诺，陷入骄傲或焦虑
- **Don't use for**：经济学效率讨论；纯学术庄子研究

## 核心命题（反功利骨架）

1. **无用之用是保全术**：《人间世》结语「人皆知有用之用，而莫知无用之用也」；不材之木、支离疏（残疾免兵役）因「无用」逃过社会砍伐/利用。「无用」是社会建构的偶然，非本质。
2. **「愚/糊涂」是矛盾优势**：「难得糊涂」（郑板桥）＝不仅无用（因智力缺陷而社会无用）有用，且保持无用和糊涂同时假装有用和聪明，极难。道家「愚人之心」（《道德经》20章）。
3. **上德不德，是以有德**（《道德经》38章，本书反复引）：矛盾的是，上德要「放弃德」。至德之世「不尚贤，不使能」（《庄子·天地》）；「端正而不知以为义，相爱而不知以为仁」。一旦立道德褒扬体系，便助长自以为是、腐败之「德」。
4. **卓越不可真诚承诺**：把卓越理想化并真诚投入，只引人误入歧途、毁灭卓越本身。《达生》工倕能徒手画线被赞，但《胠箧》「毁绝钩绳而弃规矩，攦工倕之指，而天下始人有其巧矣」——偶像化匠人即需文本否定之。
5. **名是凶器**：孔子对颜回「德荡乎名，知出乎争……名、实者，圣人之所不能胜也」（《人间世》）；尧禹为「名实相副」讨伐边族、血流百里——真诚认同卓越反致狂热杀戮。
6. **两个妾的反讽**（《山木》）：美者自美故贱，恶者自恶故贵；「行贤而去自贤之行，安往而不爱哉」——把长处当「自己拥有的」反令人厌。

## E — 可执行步骤

### 流程 A：当「我没用/不成功」自我攻击时
1. 捕获句式：「我一事无成」「这爱好没用」。
2. 转换：引用「无用之用」——你的「无用」可能是社会偶然建构，恰是免被砍伐/物化的保护。
3. 操作：允许自己有一段「非工具化」时间，不以产出衡量。
4. 自检：能否像支离疏，因「不被使用」而自由？

### 流程 B：当把技能/美德当自我时
1. 捕获：用户因「我很厉害/我很善良」而骄傲或焦虑维持人设。
2. 处方：学梓庆「臣工人，何术之有」、游泳者「吾无道」——否认拥有技艺，方不被技艺所伤。
3. 引用《胠箧》工倕警示：越真诚承诺卓越，越引骄傲；卓越需「去偶像化、正常化」。
4. 操作：做擅长的事，但内心「这不是我的，只是碰巧被委托」。

### 流程 C：破解「成功=被认可」链条
1. 捕获：用户把社会赞誉当自我价值证明（牺牛喻《列御寇》——盛装养肥终入太庙）。
2. 转换：赞誉是危险致命的；不内化成功即不上牺牛之祭台。
3. 引用《山木》二妾：不自美/不自贤，反得人爱。
4. 完成标准：能接受赞美而不「据为己有」，如壶子「不将不迎，应而不藏」。

## B — 边界

- 本 skill 是**梅勒/德安博的西方哲学视角**（受《道德经》第38章、罗蒂反讽、阿多诺「本真行话」批判影响），把反功利读作对「真诚机制/本真时代」的批判性回应。是一家之言。
- 与邓晓芒系 philosophy 技能解耦（道家比较哲学 vs 德国古典+现象学方法论），触发互斥，不互相指向。
- 「反功利」不等于「躺平/不作为」——本书主张「于内无用、于外有用」的空虚模范，是积极而从容的参与。
