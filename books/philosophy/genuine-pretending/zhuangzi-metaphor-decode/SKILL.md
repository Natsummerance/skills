# 庄子寓言解码 · 现实决策映射

> 蒸馏自《游心之路》（梅勒、德安博）。本书把《庄子》的「诀窍故事」（knack stories）与荒诞寓言读作「真实假装」的世俗教科书，而非宗教偶像或神秘境界。原书约 17 万字已存 `distill_out_zhuangzi/_raw/full.txt`。

## When to Use

- 用户的具体困境能用庄子寓言类比（职场、关系、技能焦虑、被使用/被闲置）
- 用户问「庖丁解牛/无用之大树/浑沌」对现在意味着什么
- 想把古典隐喻转成可操作的行动原则
- **Don't use for**：只做文学赏析；纯学术考据（见边界）

## 核心寓言 → 决策映射

### 1. 真实假装之树（《人间世》「不材之木」）
- **原文**：大树因「无所可用」免遭斧斤，却被立为社树——被迫接受社会角色，却未认同其宗教价值；木匠徒弟说它「既为社树，则不再无用」。
- **解码**：当你被赋予头衔/任务（「有用」），唯一选择是「陆沉」于俗——扮演它而不认同它。抵制「我的价值=社会给我的角色」的诱惑。
- **现实操作**：接下不得不做的任务，但内心保持「我非此角色」的距离（孔子对颜回「游其樊而无感其名」）。

### 2. 庖丁解牛（《养生主》）＋诀窍故事族
- **原文**：庖丁十九年刀刃若新发于硎，「以神遇而不以目视，官知止而神欲行」，合于《桑林》之舞。
- **解码**：卓越来自「disown（否认拥有）」技艺——庖丁不把解牛据为己有；醉汉坠车「骨节与人同，而犯害与人异，其神全也」；游泳者「吾无道」。
- **现实操作**：你擅长的技能是偶然所得（「命」生于此境、「义」被指派于此职），别把它偶像化。越不「自觉拥有技艺」，越不被技艺所伤（《达生》梓庆「臣工人，何术之有」）。
- **陷阱警示**：《胠箧》「攦工倕之指，而天下始人有其巧」——一旦把匠人当偶像效仿，文本就激烈否定之。卓越不可真诚承诺，否则引向骄傲。

### 3. 浑沌之死（《应帝王》）
- **原文**：南海儵、北海忽为报浑沌之德，「日凿一窍，七日而浑沌死」。
- **解码**：浑沌失败在被强加一张「脸/社会身份」并接纳了它。「待之甚善」＝对强加身份不设防，最终被「真诚的甜言蜜语」杀死。
- **现实操作**：警惕「为你好」式的社会化——他人以善意给你贴身份标签，你一旦认领即「死」。保持「无脸状态」（沃尔法特语）。

### 4. 壶子变脸（《应帝王》）
- **原文**：壶子示以「地文、天壤、太冲、未始出吾宗」诸相，季咸莫能测，落荒而逃；「至人之用心若镜，不将不迎，应而不藏，故能胜物而不伤」。
- **解码**：壶子是「真实假装者」范式——像镜子映物，不藏不迎。季咸是「假装的真实」（伪相士），列子是「假装得道」（伪学生）；壶子是「真实假装」。
- **现实操作**：面对想定义/利用你的人，不亮出固定面目；你变脸他没法归类，便伤不到你。

### 5. 螳臂当车＋养虎者（《人间世》蘧伯玉喻颜阖）
- **原文**：「彼且为婴儿，亦与之为婴儿……」；养虎者顺虎之性不犯之；爱马者以筐盛矢，扑蚊不时则被踢——「爱有所亡」。
- **解码**：与强势/危险者共事，调整自己去顺应其情绪变化，但不感同身受、不切身接纳、不产生依附。
- **现实操作**：上级反复无常时，随之扮演而内心保距；过度「出于爱关注」反成病态。

## E — 可执行步骤（解码流程）

1. **捕捉隐喻**：用户困境→匹配上表某个寓言（无对应则选结构最似者）。
2. **引原典**：务必引用对应《庄子》篇目原句（见各条），并标注本书的「真实假装」读法。
3. **区分两种解读**：说明宗教/神秘读法（庖丁＝法天圣人）vs 本书世俗读法（庖丁＝不拥有技艺的玩笑式模范），取后者做决策。
4. **给操作**：输出 1-3 条具体行动（如「接任务但不认领身份」「不把技能当自我」）。
5. **防偶像化提醒**：任何卓越都别真诚承诺，否则引骄傲（《胠箧》工倕警示）。

## B — 边界

- 本 skill 的寓言读法源自**梅勒/德安博的西方哲学视角**（受施维茨格贝尔、森舸澜、列维诺维兹影响，反对艾文贺/巴雷特的宗教性「信仰」读法）。是一家之言。
- 与邓晓芒系 philosophy 技能解耦：本批道家比较哲学，methodology skill 是德国古典+现象学；触发互斥，不互相指向。
- 不适用于：需要中立学术考据；把寓言当历史事实。
