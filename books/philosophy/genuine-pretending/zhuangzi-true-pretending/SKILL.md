# 真实假装（Genuine Pretending）· 可执行生存框架

> 蒸馏自《游心之路：〈庄子〉与现代西方哲学》（梅勒 Moeller、德安博 D'Ambrosio 著，郭鼎玮译，未读·思想家）。本书以西方哲学视角（特里林《诚与真》、海德格尔本真、罗蒂反讽主义者、弗洛伊德游戏论）破译《庄子》，核心创见是用「真实假装」取代「本真/真诚」来读《庄子》。原书约 17 万字已存 `distill_out_zhuangzi/_raw/full.txt`。

## When to Use

- 用户说「我必须活成 XX 角色」「戴面具好累」「怕自己虚伪/不真诚」「被头衔、职称、身份绑架」
- 用户在「做自己」vs「扮演社会角色」之间内耗、自我怀疑
- 用户被「本真时代」话语困扰（要独特、要原创、要真实）而焦虑
- **Don't use for**：需要中性学术定义庄子哲学时；处理与儒家的严肃伦理比较时（见下方边界）

## 核心命题（真实假装骨架）

1. **「真实假装者」≠ 百搭牌，而是小丑牌（joker）**：任博克用「百搭牌」比喻人生如荒诞扑克游戏——规则未知、矛盾本身就是游戏的一部分。本书修正为「小丑牌」：它幽默、偶然，代表绝对偶然性，是「开放性与留白」本身（《游心之路》导言）。
2. **没有本真，就无所谓虚伪**：儒家「双层一致」（名实/形名、内外真诚）要求人从心理到行动都真诚投入角色（《论语·学而》《中庸》「诚者天之道」）。《庄子》不提供「更好的真诚」或「本真」来替代，而是转向「真实假装」——若从一开始就没有本真自我，扮演角色就不产生虚假（《人间世》《德充符》）。
3. **「真人」= 没有人格的空虚模范**：「真人」是《庄子》独创词，替代儒家「圣人/君子」。《大宗师》写真人「登假于道」＝凭借道来假装一切模样；「不逆寡，不雄成，不谟士」——全是消极描述，没有固定本质（《大宗师》）。
4. **名止于实，名是宾**：「名者，实之宾也」（《逍遥游》）；「名止于实」（《至乐》）。名（头衔、名誉、社会角色）只是偶然的「宾客」，不掺入本体身份。
5. **至人无己·神人无功·圣人无名**（《逍遥游》）：拒绝内化任何社会之名，一切「实」才得以保全。宋荣子「举世而誉之而不加劝，举世而非之而不加沮」即迈出「内（形）外（名）之分」的关键一步。

## E — 可执行步骤

### 流程 A：角色压力减压（识别「真诚陷阱」）
1. 问：你焦虑的「自我」是被哪个社会之名塑造的？（父母/职场/伴侣/网红人设）
2. 标注：这是儒家式「双层一致」要求——你被要求内外都真诚地活成它。
3. 转换：把该角色当成一张「牌」——你领到了它，但不必成为它。引用「名止于实」。
4. 练习：像看电影那样体验角色情绪（会哭会笑、有生理反应），但不把这些感受「据为己有」。电影观众散场即抛诸脑后，这就是日常版真实假装。

### 流程 B：当被指责「虚伪」时
1. 反问：指责者是否预设了「你应该有一个本真自我去契合角色」？
2. 指出：儒家真诚机制本身制造了它想消除的虚伪（《人间世》孔子「德荡乎名，知出乎争……二者凶器」）。
3. 处方：不用「更真诚」辩护，而以「我不拥有这个角色」化解——「我不是在欺骗，我只是在扮演，且从不声称这是我的本真」。

### 流程 C：构建「无己」的日常操练
1. 选一件你过度认同的事（升职/外貌/道德正确感）。
2. 对其做「disown（否认拥有）」：它能带来结果，但不定义我。
3. 检验：能否像《山木》两个妾——「其美者自美，吾不知其美也；其恶者自恶，吾不知其恶也」，做到「行贤而去自贤之行」。
4. 完成标准：在角色中卓越却不自称拥有该卓越（呼应《达生》梓庆「臣工人，何术之有」）。

## B — 边界

- 本 skill 是**西方比较哲学的一家之言**（梅勒/德安博以特里林、海德格尔、罗蒂为参照系读《庄子》），本身是一种「片面的真理」，用于启发性生存策略，不当教条。
- 本书明确反对把「真人」海德格尔式地读成「本真自我」（见《大宗师》解读），引用时应呈现为「对海德格尔式《庄子》解读的批判」，而非定论。
- 与已发布的 philosophy 类技能解耦：邓晓芒系是德国古典+现象学方法论，本批是道家比较哲学，二者**不要互相指向**。触发场景互斥（本 skill 管「角色压力/身份焦虑」，方法论 skill 管「中西概念比较的方法」）。
- 不适用于：需要中立学术立场的正式论文；非生存/决策场景的纯知识问答。
