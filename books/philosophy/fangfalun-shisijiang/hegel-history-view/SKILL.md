# 黑格尔哲学史观 · 认知引擎

> 蒸馏自《哲学史方法论十四讲》第二讲「哲学史方法论新探」。不是书摘——把黑格尔—马克思一脉的「哲学史怎么写、思想史怎么读」抽成可执行的分析程序。原讲存于 `distill/fangfalun_clean/L02`。

## When to Use

- 用户在**评估一部哲学史/思想史著作**的方法论立场（如梯利式编年 vs 黑格尔式体系化）
- 用户在**写思想史论文**、处理思想史材料，要判断某个思想家在谱系中的环节位置
- 用户需要**判断一个概念/命题在哲学史链条中的来龙去脉**，定位其解决的前人矛盾与留下的新矛盾
- 用户对「历史和逻辑一致」「人体解剖是猴体解剖的钥匙」等命题想落地为操作步骤
- **Don't use for**: 单篇历史文本的阅读阐释与自我前见反思（那是 `historical-sense` 的事）、具体哲学知识问答、非思想史的一般史料考据

## 核心命题（I — 黑格尔哲学史观骨架）

1. **哲学史就是哲学**：不能把哲学史仅当史料编纂。原书点明「哲学史就是哲学」这样一句话「已经包含有历史和逻辑的相一致」（L02-13）。「大学教授的哲学史」（摆资料）与「哲学家的哲学史」（把史料融为自身体系的环节）之分野，后者才把握规律。
2. **历史与逻辑在深层同一**：表层上二者对立，进入哲学史层次则「相通的，甚至于就是同一的」（L02-13）。恩格斯正式提出：历史「常常是跳跃式地和曲折地前进的」（L02-19），故单纯追随史料会迷失方向；「逻辑的方式是唯一适用的方式……不过摆脱了历史的形式以及起扰乱作用的偶然性而已」（L02-25）。
3. **两种历史、两种逻辑**：真正的历史是「经过修正、典范形式的历史」，非原始资料堆。逻辑也分「不管真理性」的形式逻辑与「需要历史的例证，需要不断地接触现实」的辩证逻辑（L02-39）。辩证逻辑是**内容逻辑**，形式逻辑只是它形式化后的产物（L02-83）。
4. **人体解剖是猴体解剖的钥匙**（马克思）：反思的思维方式——从成熟/高级反观低级，从「现在和将来反过头看」过去（L02-45~51）。典范发展点即「每一个要素可以在它完全成熟而具有典范形式的发展点上加以考察」（L02-29）。
5. **历史以人为标准**：「有了人，我们就开始有了历史」（L02-63，恩格斯）。自然史隶属于人类史，历史必然性「建立在主观自由之上」（L02-93）。主观倾向性恰是历史客观性的灵魂（L02-97）。
6. **辩证逻辑=生命体验（历史感）**：黑格尔的辩证逻辑「涉及内容，它不是一种单纯形式」（L02-79）；其「神秘主义」只是相对于形式逻辑而言（L02-85）。「历史感就是生命感」（L02-89）——
7. **真正的历史是效果历史**：文本意义是历史生成过程，「真正的历史是一种『效果的历史』」（L02-97）；意义在解释效果中不断显深，非固定摆在那里。

## E — 可执行分析步骤

### 流程 A：评估一部哲学史著作的立场
1. 问：它把哲学史当**原始资料**（记什么、考据真伪）还是当**修正后的典范史**（抓规律、发展点）？
2. 问：史料与观点是「两张皮」外在结合，还是让历史自身展现其逻辑（L02-43）？
3. 问：作者是否「投身于研究对象」，像当事人一样体会当时的必然性（L02-43）？还是站在外面褒贬？
4. 完成标准：能一句话判定该著属于「梯利型」还是「黑格尔型」，并指出其历史感的深浅。

### 流程 B：为某思想家定位（思想史环节）
1. 把他放进「人类思想一个接一个解决矛盾」的链（呼应 L01 流程 C）。
2. 用「人体解剖」法：站在更成熟的后续发展点上反观他的**发展点**与**方向**（L02-29、45）。
3. 判定：他解决了前人什么矛盾？留下什么新矛盾？（拒绝天才叙事）
4. 完成标准：能写出「他处于 X 与 Y 之间的环节，向上通向 Z」的谱系句。

### 流程 C：运用「历史和逻辑一致」写论述
1. 先考据、爬梳文本真伪（必要前提，但非终点，L02-95）。
2. 超越偶然细节，抽出典范事件/命题作为发展点。
3. 以今人视野设身处地体会其内在冲动与方向，而非外在评判。
4. 完成标准：论述呈现「逻辑进程 = 历史进程在反思中的一贯形式」（L02-27），而非史论拼接。

## B — 边界

- 本 skill 立场即黑格尔—马克思一脉（历史感、辩证逻辑、目的论翻案），本身是「片面的真理」，用于启发不当教条。
- 「历史以人为目的、自然向人生成」是**争议性论断**（L02-65 的康德—黑格尔目的论遭自然科学立场强烈反对；热力学第二定律不支持目的论，L02-61）。引用须呈现为一家之言。
- 「辩证逻辑是形式逻辑的根」「神秘主义」之说遭分析哲学拒斥（罗素视辩证逻辑为胡说，L02-79），属学派之争。
- 不适用于：需要中立考据的纯史料工作、非思想史脉络的一般历史叙事。
