# 两种辩证法 · 概念工具

> 蒸馏自《哲学史方法论十四讲》第五讲「中西辩证法的生存论差异」（邓晓芒）。把"中西辩证法根本差异在哪"抽成可执行的分析程序。原文 11.1 万字存 `knowledge/book-library/distill/fangfalun_clean/L05_中西辩证法的生存论差异.txt`。
>
> **定位**：本 skill 管「具体概念工具」（生存论根源、自否定结构、火/气隐喻、正反合设计），`deng-xiaomang-fangfalun` 总纲管「中西比较流程」。两者解耦——总纲的流程 A 到这里借用"同中之异"，但本 skill 不重复流程 A。反语言学谱系（L04）是 L05 的**根**（L05 明言"反语言学只是表面，根子在生存论"）。

## When to Use

- 用户要**辨析一个论证是形式逻辑还是辩证逻辑**（如"这是辩证还是诡辩？""矛盾律在这里适用吗？"）
- 用户要**设计一个正反合/自我否定的分析推进**（如论文框架、思想史环节、概念演进）
- 用户要诊断**"中国式辩证法变成变戏法/权术"**的现象（对立面被外在设定、可人为掺沙子）
- 用户评估**"气"vs"火"、"天人合一"vs 内在目的论**等中西生存论隐喻差异
- **Don't use for**: 已确定要整体中西比较框架（走总纲）、要诊断中文写作的定义缺失/概念模糊（走 `anti-linguistic-tendency`）、纯形式逻辑演算

## 核心命题（I — 生存论骨架）

1. **辩证法的根源是生存论**：凡谈辩证法区别于形式逻辑（静止/孤立/片面），其本质就在"讨论人的自由、个体生存、运动发展"（L05 首段）。马克思"实践的唯物主义"即立足生存论的唯物主义。
2. **火 vs 气：两种哲学隐喻**（L05 §赫拉克利特/§老子）：
   - 西方"**火**"——**自我定形**：火无容器可装却自有形状（火苗火舌），喻**个体自由意志的能动性**，自我给自己定形才能给万物定形。赫拉克利特凭此完成"生存突围"。
   - 中国"**气**"——**被动无定形**：气需容器才成形、无孔不入是被动渗漏，喻**群体血缘共同体的自然生生不息**；"无定形"止步于气，未跳到自我定形的火。
3. **自否定（self-negation）是真正辩证法的核心**（L05 §柏拉图/§方以智）：
   - 西方（柏拉图《巴门尼德斯篇》）：抓住**同一范畴**考察它与自身的关系——"一"自身就裂出"多"，**自我否定**= 自由 = 生存冲动（"是其所不是，不是其所是"）。
   - 中国：总从**既定整体中找两个现成对立面**（阴阳二气本就在"一气"中），冲突是**外在设定**的，可人为"掺沙子""丢石头"→ 辩证法沦为**权术/变戏法**。
4. **否定之否定被中国式辩证法排斥**（L05 §毛泽东/§苏联）：20 世纪中苏马克思主义只认"对立统一"，把否定之否定规律撇开（视为自由化）；毛泽东《矛盾论》把辩证法等同于**无穷分析**（一分为二、主要矛盾/次要矛盾），邓晓芒判此为"恰好是黑格尔所反对的形而上学"。

## E — 可执行分析步骤

### 流程 A：形式逻辑 vs 辩证逻辑 辨析
1. **查对象是否"活"**：在处理运动、自由、发展、生成类问题？形式逻辑管静止/孤立/片面的形式规定，对此**无解**（L05 首段）。
2. **查矛盾类型**：
   - 一句话自相矛盾（不矛盾律冲突）→ 形式逻辑矛盾，需排除
   - 两个事物对立冲突 → 中国传统式"对立"（非逻辑矛盾）
   - **同一事物与自身矛盾、自我否定** → 真辩证逻辑矛盾（L05：柏拉图式）
3. **判辩证法成色**：看对立面是**自我派生**还是**外在设定**。自我派生=高级辩证法；外在设定+可人为操纵=退化为形而上学/权术。
4. 完成标准：能说清"此论证的自由/生存论冲动从哪来，对立面是内在还是外在"。

### 流程 B：设计正反合 / 自我否定推进
1. **立正题**：抓住一个**同一概念**（勿先拆成两半），如"一""自由""存在"。
2. **逼出自否定**：考察该概念与**自身**发生关系时的内在张力（"一"要真是"一"就不能"是一"，加了"是"即成"多"）——让对立面从正题**自己生出来**，而非外部加入。
3. **合题=否定之否定**：外在看是自我否定的体现；保留正题的真理环节而非抛弃。
4. **避坑**：勿把"一分为二"当辩证法终点（那是分析方法）；勿把对立面当现成零件拼装。邓晓芒："真正的辩证法由同一个东西的自否定产生对立面"（L05 §柏拉图）。

### 流程 C：中西生存论隐喻诊断
1. 抽文本的核心隐喻：是"火"（主动、自我定形、悲剧崇高）还是"气"（被动、自然、清静无为/喜剧）？
2. 查目的论类型：西方**内在目的论**（有限者追求无限、神人内在相通）→ 宗教异化动力；中国**外在目的论**（董仲舒"天意"依人标准施恩、天人同类相感，无需追求）→ 日常化、无超越。
3. 查异化态度：西方把规范**异化为神/金钱**以发展；中国因**害怕异化/分化**而克制个体冲动、同化于自然伦理（L05 §异化）。
4. 完成标准：能说清"该文本的个体生存动力是被发扬还是被化解"。

## 边界与争议标注

- 「**中国无真正意义上的辩证法/只有朴素辩证法**」是邓晓芒的**一家之判**（黑格尔—马克思立场）：他承认中国自古有**辩证思想因素**（《易经》变易、老子"反者道之动"、王安石"耦之中又有耦"），但判其未达"概念的思辨层次"，缺自否定。反驳方：中国传统辩证法的捍卫者（如张岱年"刚健学说"、毛泽东《矛盾论》谱系）认为"一分为二"即辩证法的中国形态；此说邓晓芒视为"把分析方法当辩证法"。引用时呈现两造。
- 「**明清启蒙有限**」论断：邓晓芒对萧萐父"明清启蒙说"**有保留**，认为李贽"童心说"、王夫之"人欲"仍落于公共性、未给个性发展留余地（L05 §李贽/§王夫之）。属争议性思想史判，当一家之言。
- 「**方以智功亏一篑**」：其"火气一元论"已引入否定辩证法萌芽，却把火归为阳气、未跨出"同一事物自相矛盾"一步（L05 §方以智）。可作思想史亮点注脚。
