# 辩证逻辑本质 · 判定引擎

> 蒸馏自《哲学史方法论十四讲》第六讲「辩证逻辑的本质」。不是书摘——是把邓晓芒「怎么判定一个逻辑/论述是真辩证的」抽出来变成可执行判定程序。原文存 `distill/fangfalun_clean/L06_辩证逻辑的本质.txt`。

## When to Use

- 用户在**分析一段关于概念自我运动、自我发展、自我否定的论述**是否站得住
- 用户要**检验一个「发展观」「矛盾观」是不是真辩证的**（而非外部冲突论、比附论）
- 用户遇到**悖论、反身性、自相矛盾**问题，想弄清其哲学含义
- 用户在**比较辩证逻辑与形式逻辑**的异同、争论「矛盾律是否被违反」时
- **Don't use for**：具体逻辑演算、数理逻辑建模、纯形式证明

## 核心命题（辩证逻辑骨架）

1. **辩证逻辑是形式逻辑之母**：形式逻辑（亚里士多德）是从柏拉图的辩证法发展引申而来；辩证逻辑不是对形式逻辑的否定，而是其「具体化理解」+「自我反思」。两者本质是一个逻辑（内容↔形式关系）。
2. **只有一种矛盾**：德文 Widerspruch 本义是「一句话自相冲突」，即同一个东西的自我否定，**不是**两个外在东西（矛vs盾）打架。中国人译「矛盾」易误解为 external conflict；真矛盾=自否定。
3. **矛盾潜伏于一切有意义命题**：「白马是马」=个别是一般=个别不是个别=A≠A，已含矛盾。完全无矛盾则只有同义反复（树叶是树叶），零信息。
4. **对立≠矛盾，差异≠矛盾**：黑/白是对立（有中间项，不需排中律）；黑/不黑才是矛盾（符合排中律，无中间项）。毛泽东「差异就是矛盾」混淆层次，导致灾难。
5. **辩证逻辑的本质=自否定**（马克思：「否定性的辩证法」）：运动根源不是内部两方外因冲突，而是**差异的内在发生**——一个东西自己跟自己不同、自己运动。列宁抓黑格尔「自己运动」即此。
6. **自由=自己运动**：辩证法是跟人一体的；自然辩证法的「自然」是向人生成的。形式逻辑已是「自由的事业」，只是遗忘了自己的自由（把自律当他律）。
7. **辩证逻辑=反身性逻辑=自我意识逻辑**：悖论（说谎者）即反身性；自我意识本身是悖论（我把自己当对象又意识到无区别）。形式逻辑无法处理「我」。
8. **辩证逻辑不可形式化/符号化**：它是创造逻辑、行动逻辑、生命逻辑，与诗/悟一体，属实践理性。试图把它数理逻辑化是对其本质的误解。

## E — 可执行判定步骤

激活本 skill 后，按以下流程处理用户的问题：

### 流程 A：检验一个论述是否「真辩证」
1. **找矛盾表述**：该论述说的「矛盾」是哪一个？是两个外在东西冲突（国共、黑白、主客），还是同一个东西的自相矛盾（A=非A）？
2. **判层次**：若是外在冲突/对立/差异 → 这是**对立统一层**，不是严格辩证矛盾层（除非追溯到自否定）。预警：多数「发展观」停在这一层，是外因论。
3. **查自否定**：论述是否把运动根源归于「一个东西自己跟自己不同、差异内在发生」？若无 → 它把运动归结为两方相互作用，本质仍是外因论（双方互为外因）。
4. **查反身性/自我意识**：论述能否处理「我」「自由」「体验」「历史创造性」？若只当工具使用（历史辩证法=辩证唯物主义+社会） → 未达辩证逻辑的人文性。
5. 完成标准：能说清该论述停在「对立层」还是抵达「自否定层」，并指出其运动根源解释是否内因。

### 流程 B：诊断一段命题是否隐含辩证矛盾
1. **取命题**：如「X 是 Y」（白马是马、树叶是绿、苏格拉底是人）。
2. **赋内容**：X 作个别/特殊，Y 作一般。则命题=个别是一般=个别不是个别 → 已含 A=非A。
3. **试罗素解**：罗素区分「属性的是」与「等同的是」化解矛盾 → 检查：等同义若有信息必退回属性义，故罗素区分无效；「是」本质是「是起来」的能动活动（海德格尔句法）。
4. **试塔斯基解**：对象语言/元语言分层隔离悖论 → 检查：一切命题如此分层后只剩同义反复，失去信息；隔离=把矛盾当病毒防火墙，未真正解决。
5. 完成标准：能说明该命题在形式层不矛盾、在内容层必含矛盾，且此矛盾不可靠隔离消除。

### 流程 C：定位一个逻辑学家/立场对辩证逻辑的态度
1. **查是否自我反思**：形式逻辑是否反思自身根源（遗忘存在/自由）？未反思 → 只「谅解」辩证逻辑有用，不「理解」它。
2. **查反身性处理**：是否把悖论/反身性隔离（防火墙）、还是承认为逻辑本性？隔离 → 停在形式层。
3. **查人文性自觉**：是否拒斥形而上学、剔除「我」、认为逻辑纯工具？是 → 无法理解辩证逻辑，因其无人文性自觉。
4. 完成标准：能判定该立场是「形式逻辑未达自我意识」还是「已达辩证逻辑」。

## B — 边界

- 本 skill 立场是邓晓芒（黑格尔—马克思辩证逻辑观），属「片面的真理」；用于批判性启发，不当教条。
- 「辩证逻辑不可形式化」是争议性论断（国内逻辑学界多数反对，试图形式化者众）；引用时呈现为一家之言。
- 「毛泽东矛盾论混淆层次」是批判性判断，用于学术反思而非政治评判。
- 不适用于：需要中立立场的正式论文直接引用其价值判断、纯形式逻辑演算任务。
