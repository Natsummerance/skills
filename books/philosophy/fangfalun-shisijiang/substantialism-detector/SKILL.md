# 实体主义检测器 · 谱系定位引擎

> 蒸馏自《哲学史方法论十四讲》第八讲「西方哲学史中的实体主义和非实体主义」。不是书摘——是把邓晓芒「如何给一个哲学立场在本体论光谱上定位」抽成可执行检测程序。原文存 `distill/fangfalun_clean/L08_西方哲学史中的实体主义和非实体主义.txt`。

## When to Use

- 用户要**判断一个哲学立场/传统在本体论光谱上的位置**（实体主义 or 非实体主义？个体 or 整体？）
- 用户在**辨析「中国是关系实在论、西方是原子论实体主义」这类流行论断**是否成立
- 用户做**中西本体论比较**，想避免「抓一个概念（气/原子）就发挥」的失误
- 用户在**评估一个理论是否含真正能动性/权能（Power）**，还是假能动性
- **Don't use for**：具体科学哲学争论（量子力学是否取消实体）、纯术语考据

## 核心命题（实体主义光谱骨架）

1. **「非实体主义」≠「反实体主义」**：非实体主义附着在实体之上（偶性、样式、属性），不取消实体；它构成对实体的理解。
2. **实体—偶性是一对范畴，不可分**：实体离开与其他实体的关系（偶性表现处）难称实体（=康德自在之物）。故**实体主义本身就是关系实在论**；「西方讲实体、中国讲关系」是误解。
3. **西方正统=整体主义实体观（非原子论旁支）**：原子论长期被教会视为歪门邪道；正统实体是能动整体（目的论统摄），基督教上帝即个体化整体。
4. **一切严格实体都含内在矛盾：机械论vs目的论（被动vs能动）**。无论个体主义还是整体主义实体，都需目的论补动力源。
5. **中西差异不在「有无实体」，而在结构颠倒**：
   - 西方：整体建立在个体之上，且整体具有个体性（上帝既普遍又个别）。个体主义实体观。
   - 中国：个体建立在整体之上，且个体具有整体性（自然大化中的泡沫）。整体主义实体观，对个体是非实体观。
   - → 区别是「结构」，不是「术语有无」。
6. **「一」的两种模式**：单一性「小一」（个别实体，可操作，奠基科学）vs 统一性「大一」（整体，形而上的，不可操作）。亚里士多德始以「小一」为第一实体。
7. **真能动性=内在自我定形/自动性（努斯、火、logos尺度）**：中国「气/水」关系需外力促成「机」（谁把它们放一起？），是被动「在场」，假权能。赫拉克利特火=自我定形+logos分寸=西方「权能场有」之源。
8. **场有哲学分两种**：西方权能场有（能动、可操作、生科学）；中国《周易》场有（非能动、惯性力、假权能）。唐力权「权能场有」本可从西方实体学说引出，不必借《周易》。
9. **现代反实体主义（休谟/康德不可知/海德格尔「在起来」）仍返本归原**：爱因斯坦场论非反实体主义（场=形式实体）；海德格尔是把亚里士多德隐藏的「如何在」发挥出来，反叛有限。

## E — 可执行检测步骤

激活本 skill 后，按以下流程处理用户的问题：

### 流程 A：定位一个立场的本体论光谱坐标
1. **查实体—关系处理**：该立场是否把实体与关系割裂（「离属性言实体」「离场有言场有者」）？若割裂 → 误读西方；西方实体必含关系。
2. **查个体/整体基点是谁**：该立场以个体为基（个体构成世界）还是以整体为基（个体是整体现象/泡沫）？前者偏西方结构，后者偏中国结构。
3. **查结构颠倒**：个体建立在整体上（中国）or 整体建立在个体上（西方）？这是根本判别维度，优于「有没有实体」术语。
4. **查「一」的模式**：其「一/太极/原子」是单一性小一（可操作个别）还是统一性大一（不可操作整体）？
5. 完成标准：能在该光谱上给立场一个坐标（个体↑整体↓ / 能动↑被动↓ / 小一↑大一↓），并指出其结构类型。

### 流程 B：检验「中国关系实在论 vs 西方实体主义」论断
1. **拒绝对立框架**：先指出西方实体主义本就是关系实在论；该对立站不住（唐力权、李存山式论断被邓文驳倒）。
2. **查原子论地位**：西方原子论是旁支非正统；正统是整体主义能动实体。莫以原子论代表西方。
3. **查中国「气」**：气也是实体（+关系，聚散），非纯粹非实体；但缺自我定形/内在动力（需外力「机」）。
4. **查能动性根源**：该论断能否解释动力源？中国场有是被动在场（假权能），西方是内在努斯/火（真权能）。
5. 完成标准：能说明中西差异是「结构+能动性根源」差异，而非「实体vs关系」有无差异。

### 流程 C：识别一种「场有/过程」理论是否含真权能
1. **查动力源内外**：该理论的「运动/自动」根源在事物内部（自我定形、内在冲动）还是外部（需第三者促成「机」、外力）？
2. **查是否需要第一推动者**：若取消外在第一推动者后又说「本来就动」→ 实为静止等价（牛顿惯性），假能动性。
3. **查 logons/尺度**：有无自我规定的分寸（logos）使运动可操作、可量化？无 → 是玄妙含混的「假权能」。
4. **查可操作性**：该理论能否导出可把握、可操纵的对象（科学精神）？中国场有惯于消解个体独立性 → 不可操作。
5. 完成标准：能判定该理论是「权能场有（真能动、可操作）」还是「假权能场有（被动、惯性、不可操作）」。

## B — 边界

- 本 skill 立场是邓晓芒的西方正统实体主义诠释，属「片面的真理」；其「中国哲学缺真能动性」「结构颠倒论」是争议性论断（关系实在论者如罗嘉昌、唐力权反对），引用时呈现为一家之言。
- 「西方现代反传统仍返本归原、未向东方投降」是邓的西方中心论判断，用于启发而非定论。
- 不适用于：量子力学基础争论的物理学裁决、需要中立立场的正式比较论文直接引用其价值判断。
