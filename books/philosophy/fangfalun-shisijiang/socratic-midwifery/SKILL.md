# 苏格拉底助产术 vs 孔子启发式 · 对话方法工具箱

> 蒸馏自《哲学史方法论十一讲》第十一讲「苏格拉底和孔子的言说方式比较」（邓晓芒）。注意：本 skill 是中西比较的**具体结论工具**（比出来的操作差异），「怎么比较」的方法论归总纲引擎 deng-xiaomang-fangfalun。原文存 `knowledge/book-library/distill/fangfalun_clean/L11`。

## When to Use

- 用户设计**教学对话/研讨课/导师制问答**，想选或混用两种对话范式时
- 用户起草**访谈提纲**：深挖型访谈（苏格拉底式追问链）vs 引导型访谈（权威答疑式）
- 用户要构造**苏格拉底式追问链**（从例子到定义、暴露矛盾、逼近普遍性）
- 用户做**中西思维比较**的具体案例引用（言说标准、师道、权力话语）
- 用户诊断一段对话为何失效：鸡同鸭讲？诱导审问？诚心悖论？
- **Don't use for**: 儒家思想内容史（本 skill 只谈言说形式）、对孔子的人格评判——邓晓芒的批评针对话语结构，引用时保持学术中立

## 核心命题（I — 方法论骨架）

1. **同源不同质**：两人都是中西伦理学源头、都述而不作。但孔子不写是因为「述而不作」——转述古代圣贤；苏格拉底不写是因为真理只能在追求中逐步显现，谈话只是道路，固定成书反而封死。
2. **言说标准的分野**：苏格拉底的标准**在言说本身**（语言的逻辑层次）；孔子的标准**在言说之外**（内心体验与感悟，说不出来）。前者产生定义与推理，后者产生语录与体会。
3. **「是什么」先于「怎么样」**：讨论美德是否可教之前必须先问美德是什么——实体问题逻辑上先于属性问题。「仁」在《论语》中从未被问「是什么」，只被问「如何做到」。
4. **对话性质的根本差异**：苏格拉底是两个自由人的平等对话（他提问、对方回答）；孔子是居高临下的权力话语（弟子提问、他答疑），以「不愤不启，不悱不发」为门槛。
5. **效果分野**：开放式辩难让双方立场在争论中互相转化（《普罗塔哥拉篇》辩到最后立场互换）、即使无结论也提升矛盾层次，为后人留下超越空间（吾爱吾师，吾更爱真理）；结论式传授树立不可超越的圣人，发展只能是积淀型原地转圈。

## E — 可执行分析步骤

激活本 skill 后，按以下流程处理用户的任务：

### 流程 A：苏格拉底式追问链构造（用于教学/访谈设计）
1. **锁定目标概念**（如「勇气」「公平」），禁止从例子直接下结论。
2. **先问「是什么」**：「你要谈 X 是否 Y，那 X 是什么？」——确立单数的本质问题，拒绝端出「一窝」复数例子。
3. **收集反例驱动修订**：对每个候选定义找反例，逼对方自己修正。
4. **归类上升**：把概念归属到一个更大的种之下（「美德就是知识」=给概念找类属），再补最近的属差（亚里士多德「种加属差」）。
5. **只守一条约束**：对方唯一必须遵守的是话语本身的逻各斯——让人听得懂、不自相矛盾；除此之外完全自由。
6. **接受开放结局**：允许「美是难的」式收尾——没找到定义但排除了错误答案，思维层次已提升。不要强行闭环。

### 流程 B：助产术合规检查（防走样）
1. **自由出口检验**：结论是否由对方自由说出？只有对方不受限制地说出你也想到的结论，它才被证实为客观；诱导、施压、「动之以情」得出的同意一律无效。
2. **预设检查**：你可以估计对方的走向，但不得用预设立场限制对方；临场发挥≠漫无目标，靠话语逻辑牵引方向。
3. **低姿态检查**：自称无知不是话术，是对自己的已知保持反思态度——「自以为知其实却不知」的情况太多。
4. **红线**：一旦变成审讯式诱导（刑事学家最反对的那种），就不再是助产而是接生失败。

### 流程 C：孔子启发式场景识别（何时适用/失效）
1. **前提默认结构**：孔子的对话有一个永不说出的前提——求教者已立志成人（「想要仁」这个意向本身是全部对话的地基，连「非礼勿想」都不用说）。**适用条件**：对方确有此志向；**失效条件**：对方无此意向则对话根本不存在，只会落到骂「小人」「不仁」。
2. **因材施教机制**：同一概念对不同人给出完全不同的回答（七次问仁七种答法），针对性敲打缺点（对多嘴的司马牛说「仁者其言也讱」）——这不是定义而是情境化教训。
3. **诚心悖论预警**：没有诚心进不去（他不愤不启），有了诚心跳不出来（已把老师摆在真理位置）——设计此类对话时要意识到这个结构性陷阱。
4. **情感制高点识别**：宰我问三年之丧，孔子诉诸「汝安乎？」的情感表白而非论证；权力话语来自道德—情感制高点，往往滑向情感竞赛。分析现实中的权威话语可用此模型。
5. **合法用途**：师徒传承、价值观养成、需要明确结论的技能训练场景中，「答疑解惑+因材施教」效率高于开放式辩难——两种方法各有生态位。

### 流程 D：对话诊断（用户拿来一段真实对话时）
1. 判型：谁在提问？标准在语言内部还是语言之外？有无来回辩难？
2. 找断点：是「鸡同鸭讲」（缺共同言说标准）、「一窝例子」（未上升到本质问题）、还是答非所问（司马牛式错开）？
3. 开处方：该补追问链（流程 A）还是补前提共识（流程 C.1），或承认这是权力话语场景并改用流程 C 的框架理解。

## B — 边界

- 本 skill 的对比结论是邓晓芒基于《美诺篇》《普罗塔哥拉篇》《大希庇阿斯篇》与《论语》问仁章的文本细读，属一家之言；「叩其两端」解为上下两端（统治者/百姓）是其私解，未经儒学界公认，引用需注明
- 对孔子的批评针对**言说结构与权力话语效应**，不构成对其人格或思想价值的整体评判；儒家内部亦有丰富的对话传统未被覆盖
- 「中国传统=积淀型原地转圈」是争议性大判断，仅可用于启发，不可当作定论输出
- 不适用于：历史考据（父子相隐之争等只存目）、非对称场景外的日常聊天
