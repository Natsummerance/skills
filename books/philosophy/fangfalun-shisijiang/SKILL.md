# 邓晓芒哲学史方法论 · 认知引擎

> 蒸馏自《哲学史方法论十四讲》（邓晓芒，三联书店第三版）。不是书摘——是把他「怎么想」抽出来变成可执行的分析程序。原书 44 万字已分讲存于 `knowledge/book-library/distill/fangfalun_clean/`。

## When to Use

- 用户在做**中西比较**（文化、哲学、思维方式、艺术审美）且想要深度而非比附时
- 用户在**反思自己的学习方法/研究方法**「为什么我读了很多书却没有长进」
- 用户需要**评估一个翻译/引进概念是否被误读**（如「封建」「自由」「理性」在中文语境的错位）
- 用户写论文需要**处理思想史材料**、判断某个思想家在谱系中的位置时
- **Don't use for**: 具体哲学知识问答（那是知识库的事）、日常决策、非学术场景

## 核心命题（I — 方法论骨架）

1. **有方法 ≠ 有方法论**：中国传统「有方法而无方法论」——木匠口诀、禅宗点拨都是秘传的操作，没有对方法本身的公开反思。方法论 = 对方法的「论」，必须公开、理性、人人可学。
2. **智慧 vs 爱智慧**：中国人有智慧（用于治国、解脱、人身），缺的是「对智慧本身的爱」——不计功利地追求真理本身。实用理性把一切智慧工具化，等于智慧的自杀。
3. **真正的哲学革命是方法革命**：苏格拉底辩证法、培根《新工具》、笛卡尔《方法谈》、康德先验方法论、黑格尔逻辑学、胡塞尔《逻辑研究》——大哲学家都从方法入手；范式革命优先于内容增添。
4. **哲学史就是哲学**：不能把哲学史仅当史料编纂。「大学教授的哲学史」（梯利式摆资料）vs「哲学家的哲学史」（黑格尔式把史料融入自己体系的环节）——后者才可能把握规律。
5. **学习哲学史就是学习哲学**（恩格斯）：撇开哲学史的聪明只是机智，不是哲学素养。

## E — 可执行分析步骤

激活本 skill 后，按以下流程处理用户的问题：

### 流程 A：中西概念比较诊断
1. **锁定表面等同**：找出中西方各自「看起来相同」的概念对（如「道」vs「逻各斯」、「天人合一」vs 泛神论）
2. **拒绝比附**：禁止「古已有之」式论证——问「这真是同一个东西吗？背后的差异是什么？」
3. **挖掘同中之异**：恰恰在看似一致的方面指出差异，才是理解的开始（文化融合第三阶段）
4. **追溯错位根源**：用「十大文化错位」模式检查：选择性接受？本体论搁置？概念偷换？
5. 完成标准：能说清「同一词语背后两种思想传统各自的预设」

### 流程 B：方法论自检（用户自己的研究/学习）
1. 问：你的方法是秘传口诀还是可公开反思的程序？能否教给别人？
2. 问：你在追求效果还是在追求真理本身？（实用理性检测）
3. 问：你有没有对自己的方法拉开距离做二次反思？
4. 处方：从「奇技淫巧」升级为「道术」——把偶然奏效变成可复现的原则

### 流程 C：思想史定位
1. 把研究对象放进「人类哲学思想一个接一个解决矛盾」的发展链
2. 判断：他解决了前人的什么矛盾？留下了什么新矛盾？
3. 拒绝天才叙事：任何思想都有教育与文化前提，「从脑子里蹦出来」的思想留不下

## B — 边界

- 本 skill 的立场是邓晓芒的立场（德国古典哲学+现象学融合传统），本身是一种「片面的真理」；用于批判性启发，不当教条输出
- 「中国无爱智慧」是争议性论断（反例：庄子之「游」、魏晋玄学的纯粹思辨），引用时应呈现为一家之言
- 不适用于：需要中立立场的场合（如正式论文直接引用其价值判断）、非中西比较的一般问题
