# 十大文化错位图谱 · 误诊模板

> 蒸馏自《哲学史方法论十四讲》第十四讲「中国百年西方哲学研究的十大文化错位」。把十个最普遍的「中西混用误读」抽成**可即查即用的诊断模板**。总纲 `deng-xiaomang-fangfalun` 只用了本讲的「同中之异」原则，本 skill 是其**十大具体案例库**的展开，二者分工明确、互指互补。原文明文存 `knowledge/book-library/distill/fangfalun_clean/L14_中国百年西方哲学研究的十大文化错位.txt`。

## When to Use

- 用户拿出一个**中西概念混用/比附的论述**，要快速定位「它错在哪、属于哪种错位」
- 用户写论文做**中西比较**，需排查自己是否落入某类错位
- 用户要**评估某个引进概念的本土化是否扭曲**（如「理性」「自由」「科学」「辩证法」的中文用法）
- **Don't use for**：纯翻译技巧（见 philosophy-in-chinese）、纯功利动机分析（见 pragmatism-bias-checker）；本 skill 聚焦「概念层面的误诊分类」

## 文化融合三阶段（定位前提）

1. **第一阶段（拒斥）**：只见异、互相排斥，以「古已有之/我们不差」拒之门。
2. **第二阶段（比附）**：发现同/相通，以老解佛、拉拢比附，掩盖大量不可通。
3. **第三阶段（同中之异）**：在已视为「相同」处重新用陌生化眼光挖出**差异**——这才是真正融合的开始。本 skill 的十个错位，全是停在第二阶段、把「同」误当「同」而漏掉「异」的病例。

> 诊断口诀：**表面越像，越要查异**。在大致相同的方面指出背后差异，才是理解起点。

## 十大错位模板（即查即用）

每个模板含：① 西原本貌 ② 中误读 ③ 错位类型 ④ 快速识别信号

### 1. 严复对进化论：选择性接受
- 西：达尔文进化论是中立科学；赫胥黎用于伦理则推导「优族存、劣族亡」。
- 中：删科学本体论/价值层，改「任天为治」为「与天争胜」救国；与公羊三世/尚力/变法先见揉合。
- 类型：**选择接受 + 本体论删削 + 先见揉合**。
- 信号：引进时「只取能激发斗志/有用的部分」，删掉「无用」的形而上学。

### 2. 王国维对叔本华：活剥（本体论搁置）
- 西：意志=世界本质（本体），人生痛苦根源=原罪，解脱在彼岸/天启。
- 中：砍本体论，只取「人生即欲望即痛苦」；译 idea 为「实念」/「物」，去柏拉图传统；此岸顿悟成佛，去原罪/彼岸。
- 类型：**本体论搁置 + 概念偷换（译名） + 附会佛教**。
- 信号：把西方本体论哲学改造成「人生哲学/文学」；关键译名被悄悄改换。

### 3. 胡适对杜威：主义降为技术
- 西：杜威实用主义是哲学式普遍原则，容纳信仰。
- 中：降为「实验主义」方法（大胆假设小心求证），以中国传统自然实在论取代信仰位置；限于考据式实用理性。
- 类型：**主义→技术 + 朴素自然主义替信仰**。
- 信号：把「哲学/主义」说成「只是方法/工具」，拒绝其信仰/形而上学层。

### 4. 牟宗三对康德：误读「先验的观念性」
- 西：经验的实在论 + 先验的观念性**不可分割**，共构知识。
- 中：把「先验的观念性」读成「先验的虚假性」（贬义），以为康德只靠经验立科学，道德需中国哲学补（西方物质/中国精神老调）。
- 类型：**概念误读（文本硬伤） + 以中补西立场**。
- 信号：把西方概念里的「互补项」读成「缺陷项」，引出「中国补西方」结论。

### 5. 「理性」reason：逻各斯+努斯 误为「理/性」
- 西：理性=逻各斯（语言/表达）+努斯（灵魂/能动超越/自我立法），是功能。
- 中：理=玉石纹理/自然法则/实体，是现实存在；天理靠直觉体悟非言语逻辑（程颐「耳闻口道者心实不见」）。缺逻各斯与努斯。
- 类型：**概念偷换（实体化） + 缺失超越精神**。
- 信号：把西方理性主义等同于宋明「理/性」，忽略语言与自由意志内核；新理学/新道学「逻辑如何过渡现实」失败。
- 关联：philosophy-in-chinese 流程A 定名反测试。

### 6. 「科学」science：实用化=技术
- 西：科学源于惊异/爱智慧，拒斥实用，是非功利生活方式。
- 中：从「有用无用」看科学；科玄论战双方都找「万能工具」；马列之「科学」因其革命成功而非真理体系。
- 类型：**目的倒置（工具化） + 精神空白**。
- 信号：以「实践成功=科学」判定，无人因好奇心读原文；科学精神丧失致非理性主义填空。

### 7. 「辩证法」dialektik：降级为变易/矛盾
- 西：根于对话/概念辩证法（主观辩证法），客观辩证法是主体对象化；核心是**自否定（Widerspruch=一句话自相冲突）**。
- 中：等同于《易经》变易、老子「反者道之动」、韩非「矛盾」（实物式矛与盾）；毛泽东「差别就是矛盾」，取消自我否定。
- 类型：**朴素化降级 + 实物思维替概念思维**。
- 信号：把辩证法当「孙子兵法/驭人之术/变戏法」；讲「对立统一」却丢「自否定」之根。

### 8. 「实践」Praxis/Praktik：降为知行践履
- 西：含试探/冒险/首创（Praktik=未必被允许、未必有把握的措施）；马克思=自由自觉感性活动。
- 中：纳入「知行合一」旧框，实践=既定原则下按规程操作+用效果检验；抽掉情感/自由意志/创造。
- 类型：**旧框套用 + 抽离自由精神**。
- 信号：实践=「下去锻炼/同吃同住懂疾苦」式规训，而非自由首创的冒险。

### 9. 「存在」being/sein：系词逻辑义丢失
- 西：being 根本义是逻辑系词「是」，引申动词「有/在」与名词「存在者」；ontology 由系词的能动超越（努斯）建立。
- 中：古汉语无固定系词，以「有/存在/在」译丢失系词逻辑义；ontology 译「本体论/存在论/是论…」争而无对应。
- 类型：**语法缺位致义丢失 + 逻辑/自由精神双缺**。
- 信号：一词多译并存（是/有/在/存在）且换译不注；用「拥有」低层义替「是」最高范畴。

### 10. 「自由」freedom：附会老庄/儒家
- 西：以意志自由为前提（努斯+逻各斯自我立法），是法权/权利（穆勒：群己权界）。
- 中：① 附道家庄子「无意志的自由」=任自然/无执着；② 附儒家「大丈夫」=他律内化的担当（杀身成仁）。严复译《论自由》为《群己权界论》却仍混老庄+儒家。
- 类型：**双重附会（无意志自由 / 无自由意志） + 权利义丢失**。
- 信号：把自由说成「逍遥/克己担当」，不讲个体自决立法与法权界限。

## 诊断流程（给用户用）

1. **锁定混用对**：找出论述中「西方概念 X ↔ 中国概念 Y」的对应。
2. **判阶段**：是比附同（阶段二）还是已挖同中之异（阶段三）？
3. **对表定位**：用上面十模板逐一比对，命中哪条（可在一条或多条间叠加）。
4. **定错位类型**：选择接受 / 本体论搁置 / 概念偷换 / 主义降技术 / 附会 / 朴素降级 / 语法缺位——往往复合。
5. **给修正处方**：补回被删的本体论/逻辑/自由精神层；标明「此处同、此处异」；必要时回到 philosophy-in-chinese 重定名。
6. 完成标准：能指出「该论述错在模板 N，缺失的是西方的 ___ 精神/层面，被中国的 ___ 先见替掉」。

## 共性结构（十错位的底层公式）

> **西方概念（含逻各斯+努斯/本体论/自由精神）** ——被中国先见拦截——> **只取实用/道德/人生/政治层，删本体论，降概念思维为实物/直觉思维，附会老庄/儒家/佛家**。

所有错位共享三断点：① 删本体论/形而上学 ② 丢逻各斯（语言逻辑）与努斯（自由超越）③ 以中国固有「理/道/自然/心性/践履」先见收编。

## B — 边界
