# 实用主义偏向检测 · 百年引进检讨清单

> 蒸馏自《哲学史方法论十四讲》第十三讲「对中国百年西方哲学研究中实用主义偏向的检讨」。把「中国人怎么把西方哲学读歪」抽成可执行的偏差检测程序。原文明文存 `knowledge/book-library/distill/fangfalun_clean/L13_对中国百年西方哲学研究中实用主义偏向的检讨.txt`。

## When to Use

- 用户要**审视一个「洋为中用」方案/引进概念是否扭曲了原意**（如某理论被当工具、当法宝、当救国手段）
- 用户在做**中西学术引进、本土化、创造性转化**的批判性评估
- 用户警惕自己或他人**以「有用没用」作为取舍标准**对待理论
- 用户要**区分「政治实用主义」与「技术实用主义」**两种痹症
- **Don't use for**：纯技术分析（如工程移植）、非理论性决策；本 skill 聚焦「理论被功利化」的认知偏差

## 核心命题（I — 方法论骨架）

1. **两种实用主义**：**政治实用主义**（富国强兵、治国平天下、救国救民，支配一切）与**技术实用主义**（把理论当解决问题的法宝/技术/工具，如「马克思主义是法宝」「试验主义」）。二者同源、相辅，是「同一根系上两株病梅」。
2. **先见不可避免，但须反思**：任何民族接受异文化都有先见（Vorurteilen=成见/偏见）。百年接触后必须回头铸造新视野、做「视野融合」——否则永远是既定成见。
3. **「好/坏」标准是传统的**：我们用传统标准（有无实效）衡量西方理论，凡与传统格格不入者易被评「不好」——这套「以实际后果+传统标准判优劣」本身就是传统思维模式（墨子三表法：本圣王之事、原百姓耳目、观国家之利）。
4. **知行合一的副作用**：中国「知就是行、行必按知的规范」贴得太紧，挤压了理论独立发展空间。西方优势恰在「知行相分」的「毛病」——理论可超前、可无用，一旦条件具备便爆发出现代科学。**为真理而真理、为学问而学问**是稀缺而必要的姿态。
5. **最高层的实用主义仍是实用主义**：王国维吸收叔本华只取人生哲学、砍掉其本体论与基督教原罪背景——这是「对人生有用」的最高层实用主义，仍非为真理而真理。
6. **真正摆脱束缚的标杆是陈康**：提倡客观性，「每一结论皆从论证推来…人我不混，物我分清，一切取决于研究对象」。纯学问本身即具政治颠覆性（最脱离政治者最颠覆政教循环）。
7. **实用主义的当代变形**：政治实用主义失势但随时卷土重来；技术实用主义恶性膨胀、层次下移——哲学被当政策工具、管理技巧、晋职招牌、「最新某某哲学」卖钱卖名。极左与极右同源。

## E — 可执行分析步骤

### 流程 A：检测一项「洋为中用」是否扭曲原意

1. **定位取舍点**：引进时是否**选择性接受、有评论、有改造、有删削**？删掉的是哪部分（通常是本体论/形而上学/纯理论层——严复删科学本体论，王国维砍叔本华意志本体论）。
2. **追问动机层**：是政治实用（救国/富强）还是技术实用（当方法/法宝）？或是二者混合？动机是否先于、压倒了客观理解？
3. **检查「本体论搁置」**：原理论的形而上学根基是否被以「无用」为由砍掉，只剩可用的「方法/人生/工具」层面？→ 这是最典型的实用主义错位。
4. **检查「标准倒置」**：评价该理论的好坏，是否用了引进前的传统标准（实效/圣王/百姓之利）而非理论自身逻辑？
5. **检查「知行紧贴」**：是否要求理论立刻「行」、立刻见效，拒绝给理论独立发展空间？
6. **检查「法宝化」**：是否把最高深的主义（马克思主义、实用主义、某西方理论）降格为「解决问题的技术/符咒/立竿见影的法定」？
7. 完成标准：能说清「原理论被保住了什么、丢掉了什么、丢掉的恰好是其命脉（本体/逻辑/自由精神）」。

### 流程 B：两极对照自检（严复极 ↔ 王国维极）

任何引进方案都可落在两极高间，自检落点：
- **严复极（低层政治实用）**：取培根归纳法/进化论「富强有用」→ 改造原文以激发危机感（「与天争胜」vs「任天为治」），删本体论。
- **王国维极（高层人生实用）**：取叔本华人生哲学「指导人生/艺术有用」→ 砍宗教哲学/原罪/本体论。
- **健康极（陈康/杨祖陶）**：为真理而真理、为自由而自由，客观到「使欧美学者以不通中文为恨」。
- 你的方案偏哪极？若只在两实用极间摇摆，即为世纪之交错位的重演。

### 流程 C：识别「实用主义对实用主义」的伪论战

- 标志：争论双方都默认「理论须有用」，分歧只在「用哪种、用什么层次」——如胡适（技术实用）vs 李大钊/陈独秀（政治实用），并非反实用主义。
- 检测：辩护理由是「学理批判」还是「同样是实用主义的策略辩护」？若后者，论战未触根本。
- 延伸：50 年代大批判实用主义是政治符号运动，零学术澄清——警惕任何「批判某主义却只用上纲上线」的模式。

## B — 边界

- 本 skill 立场是邓晓芒的：批判实用主义偏向，主张为真理而真理。这是一家之言（争议性论断）。
- 严复/王国维的取舍在**救亡语境下可辩护**（「任天为治」客观译出会消极）；但不可把那种方式当**今天**常态学习态度。
- 「中国无纯粹为学问精神」是作者判断，引用时呈现为批判性视角而非定论。
- 不替代具体学术史考证；本 skill 给偏差模式，个案细节需回原文核对。
