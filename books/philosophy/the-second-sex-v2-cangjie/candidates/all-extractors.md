## frameworks

```yaml
- id: f01
  title: 恋爱消融识别框架
  type: framework
  source_chapter: 恋爱中的女人章
  source_quote: |
    "凯瑟琳在《呼啸山庄》中说：'我是希思克厉夫'，这是所有恋爱的女人的呼喊……她让自己的世界在偶然性中崩溃，她生活在他的天地中。"
  summary: |
    自我消融的识别指标：①语言上「我是他」式同一化
    ②世界收缩为他的天地③幸福绑定于被承认（当他说'我们'）。
    分析三问：这是爱还是消融？消融是自愿还是处境所迫？
    双方都在消融还是单向？
    警示：不评判感情本身，只分析结构。
  tags: [love, dissolution, beauvoir]

- id: f02
  title: 客体-主体逆转分析框架
  type: framework
  source_chapter: 妓女与艺妓章
  source_quote: |
    "她们开始时把自身作为客体奉献给男人，重新成为主体。她们不单像男人一样谋生，而且生活在几乎只属于男性的圈子里。"
  summary: |
    波伏瓦的辩证悖论：边缘位置可能发生客体→主体逆转
    （妓女/艺妓获得近似男性的独立）。
    分析要点：逆转的真实代价是什么？谁有资格逆转？
    该案例是否可推广？警惕浪漫化生存策略。
  tags: [object-subject, reversal, dialectic]
```

## glossary

```yaml
- id: g01
  term: 恋爱的女人
  author_definition: 波伏瓦类型学概念——以自我消融方式体验爱情的女性生存形态。
  key_distinction: ≠所有恋爱中的女人——是一种被处境塑造的类型而非普遍本质。

- id: g02
  term: 客体-主体逆转
  author_definition: 从被物化的奉献者重新成为自决主体的辩证过程（妓女/艺妓案例）。
  key_distinction: ≠解放的普遍路径——波伏瓦明示其偶然性与代价。

- id: g03
  term: 走向独立
  author_definition: 下部终章的出路论证——通过超越性劳动实现主体地位。
  key_distinction: ≠经济独立即可——精神超越性是必要条件。
```
