# 言说方式比较

## R — 原文 (Reading)

> "苏格拉底以逻辑逼问使对方陷入自相矛盾；孔子启发式语录、述而不作。"
>
> — 梅勒/多霍斯，L11 苏格拉底和孔子的言说方式比较

---

## I — 方法论骨架 (Interpretation)

言说方式即思维方式的外显：苏格拉底式对话以逻辑逼问让对方自己暴露矛盾（否定性推进）；孔子式语录正面示范、因材施教（肯定性启发）。分析任何思想传统的入口：它如何提问？如何回应反驳？知识如何传递？对话录与语录体的差异暴露真理观差异。

---

## A1 — 书中的应用 (Past Application)

### 案例: 苏格拉底vs孔子的对话形态（L11）
- **问题**: 两位东西方宗师为何留下如此不同的文本？
- **使用**: 对话录展示逻辑逼问的过程；论语记录结论式启发。
- **结果**: 言说方式差异折射辩证法vs处世智慧的传统分野。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **采样文本**
   - 完成标准: 从两传统各取一段典型对话

2. **标注推进方式**
   - 完成标准: 否定性逼问/肯定性启发/格言断言

3. **追溯真理观**
   - 完成标准: 真理被视为产物还是传承

4. **输出对照卡**
   - 完成标准: 提问+回应+传递 三行表

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 把言说方式差异当优劣判定——邓晓芒有倾向性，使用者需自持

### 作者在书中警告的失败模式

- 对孔子述而不作的解读偏消极；语传统亦有对话性未被充分处理

### 作者的盲点 / 时代局限

- 比较哲学的对称性问题——用西方「对话」标准衡量语录体

### 容易混淆的邻近方法论

- socraticism-detector / role-occasion-matching
