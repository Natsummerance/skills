# 《疯癫与文明》· 理性如何划界

> 蒸馏自米歇尔·福柯《疯癫与文明：理性时代的疯癫史》（刘北成等译）。核心问题不是「疯人如何被治疗」，而是**「非理性的沉默的考古学」**：「我的目的不是撰写精神病学语言的历史，而是论述那种沉默的考古学。」原文存 `knowledge/book-library/distill/philosophy_deep/foucault_madness.txt`。

## When to Use

- 用户讨论精神疾病的社会建构、「正常/异常」边界由谁划定
- 分析排斥机制（收容所/监狱/诊断标签）的理论需求
- 读福柯其他著作（规训与惩罚）前的谱系起点
- **Don't use for**：精神医学的临床内容；把本书当史学实证研究（其史料处理有争议）

## 核心命题（I）

1. **序言的方法宣言**：「我们却不得不撰写一部有关这另一种形式的疯癫的历史，因为人们出于这种疯癫，用一种至高无上的理性所支配的行动把自己的邻人禁闭起来，用一种非疯癫的冷酷语言相互交流和相互承认」——写疯癫史是为了暴露理性自身的疯癫。
2. **文艺复兴：愚人船的想象**：「无可置疑，自15世纪以来，疯癫的形象一直萦绕着西方人的想像」——从博斯《愚人船》到布勒哲尔，疯癫尚是流动的、被放逐去朝圣的形象，未被绝对隔离。
3. **古典时期：大禁闭（1656 总医院）**：「在古典时期的大禁闭中，最基本的也是最新的特点在于，人们被禁闭在纯粹道德的城市中，在那里，毫不妥协、毫无保留地用严厉的肉体强制来实行统治心灵的法律。道德自愿地像商业或经济那样接受行政管理」——疯人、穷人、浪子、囚犯混同收容，疯癫成为道德错误。
4. **18世纪末改革的双重面孔**：
   - 图克（Tuke）休养院：「'家庭'既是图克的出发点，又是他所逐步实现的目标……使'家庭'发挥一种解除精神错乱的作用」——以家庭道德场域实施观察与规训。
   - 皮内尔（Pinel）：宗教作为治疗资源——「正是在这方面，宗教经常具有治疗效果」，并记录了伏尔泰式病例叙事。
   - 表面的「解链解放」实为更深的控制：从肉体禁闭转为道德改造。
5. **疯癫的医学化**：古典时期「疯癫虽然从激情出发，但依然是灵与肉的理性统一体中的一种剧烈运动……这种剧烈运动很快就摆脱了该机制的理性」——疯癫被逐步纳入自然因果链条，最终成为纯粹的精神病对象。

## E — 可执行步骤

### 用福柯框架分析一个「排斥机制」（四步）
1. **断代定位**：该机制的先例形态是什么？（愚人船式流放 / 大禁闭式收容 / 疯人院式改造）
2. **找混杂性**：谁和谁被关在一起？——混杂名单暴露划分逻辑的真实标准。
3. **识别话语**：什么样的语言被允许描述被排斥者？谁有权说话？
4. **看「仁慈」的权力面**：人道化改革的表象下，控制是放松还是转移到了更深层？

### 应用示例
现代职场「心理韧性」话语 → 谁定义韧性？不达标者被如何安置？关怀话语是否构成新的规训？
