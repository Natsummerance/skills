# 巴赞现实主义理论 · 电影是什么

> 蒸馏自安德烈·巴赞《电影是什么？》（崔君衍译，缩编定本）。电影理论的奠基文本：影像的本体论地位、电影史的心理学起源、蒙太奇的适用边界。**注意其与爱森斯坦蒙太奇学派的论战背景**——巴赞的「禁用」是有条件的修辞。原文存 `knowledge/book-library/distill/film_bazin_godard/bazin_cinema.txt`。

## When to Use

- 用户问「长镜头美学是怎么回事」「为什么说蒙太奇会扭曲现实」
- 分析一部影片的现实主义策略（罗西里尼/德西卡/雷诺阿/塔蒂）
- 电影史论题中需要巴赞立场的准确表述
- **Don't use for**：类型片娱乐分析；与戈达尔语法对照时（用 godard-jump-cut-grammar）

## 核心命题（I）

1. **影像的本体论同一性**：「被摄物和它的照片之间有着本体论的同一性」——摄影影像不是对现实的解释，而是「现实的真正印记，是一种不显颜色的光影印模」（摄影影像的本体论篇）。
2. **蒙太奇的风险**：早期电影「用现实的幻象取代了本真的现实，它是抽象性（黑白双色和银幕平面）、约定性程式（如蒙太奇法则）和客观现实的化合物……忽视现实的倾向便愈发滋长。再加上因循与慵懒，最终连他自己也分不清哪里是艺[术]」（完整电影篇注区）。
3. **「被禁用的蒙太奇」的适用场景**：评拉摩里斯《白鬃野马》《红气球》——当动物或儿童的主体性需要被尊重时，「通过《小驴比姆》，拉摩里斯已经显示出他的独具一格的创作灵感」（被禁用的蒙太奇篇）——禁用是针对特定题材的美学选择。
4. **完整电影的神话**：电影史的动力不是技术成熟而是「完整电影」的心象——对真实复制的完整幻觉的追求先于技术实现（同名篇）。
5. **戏剧与电影的相互成就**：「蹩脚的'罐装戏剧'帮助了真正的戏剧领悟自身规律。电影也促进了戏剧场面调度观念的革新」（戏剧与电影篇）——媒介互动论。
6. **塔蒂：创造世界先于逗笑**：「正像所有十分伟大的喜剧演员一样，塔蒂在让我们发笑之前，首先创造了一个世界。这个世界是以塔蒂扮演的人物为中心安排的，就像超饱和的溶液围绕着投入液体中的盐粒形成结晶一样」（于洛先生和时间篇）。

## E — 可执行步骤

### 用巴赞标准分析一场戏（五问）
1. **空间完整性**：这场戏是否保持时空连续？（还是靠剪辑重组？）
2. **剪辑功能**：蒙太奇是在「解释现实」还是在「尊重现实的暧昧」？
3. **景深与调度**：画面内有哪些并置的信息层次让观众自行选择？
4. **演员与对象的关系**：表演是否让位于人与环境的真实关系？
5. **结论定位**：这场戏的现实主义等级——印记级 / 幻象级 / 程式级。

## B — 边界

- **论战背景声明**：巴赞的「禁用蒙太奇」是对苏联学派（爱森斯坦「杂耍蒙太奇」）的论战反题，不是普遍禁令；他本人也分析过蒙太奇的合法用法。
- 本书为缩编选集（原四卷本），非全集；译者前言含崔君衍的个人学术史叙述，与正文区分。
