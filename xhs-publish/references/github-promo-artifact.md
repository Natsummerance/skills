# github-promo-post artifact contract

Expected input directory:

```text
artifacts/
├── title.txt
├── body.txt
├── topics.txt
├── metadata.json
└── images/
    ├── xhs-01-cover.jpg
    ├── xhs-02-pain.jpg
    ├── xhs-03-fast.jpg
    ├── xhs-04-fix.jpg
    ├── xhs-05-convert.jpg
    └── xhs-06-cta.jpg
```

`metadata.json` fields: `title`, `body`, `topics`, `images`, `source_urls`, `version_state`.

The publisher must use the artifact as-is after validation. Do not add URLs, topics, claims, images, or bypass flags.
