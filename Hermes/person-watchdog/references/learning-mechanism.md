# 自动学习机制：纯本地、不重训练、持续自我强化

> 设计约束：不引入飞书回复反馈、不重训练模型、不上传任何数据。全部学习都在本地 `learning_data.json` 中完成，进程重启后继续生效。

## 三条学习通道

### 1. 背景学习（运动门控自适应）
- 空闲时以 160 宽灰度帧做帧差，背景模型用学习率 `motion_learn_rate: 0.05` 持续吸收光照/环境缓慢变化。
- 效果：窗户光变化、显示器亮度波动不会误触发"运动"；空闲 CPU 趋近于零（只做小图灰度帧差）。
- 复位：`--reset-learning`。

### 2. 误报区域记忆（抑制海报/假人/重复误报区）
- 判定启发式：同一画面区域 ≥ `false_region_repeat: 3` 次"无脸 + 停留 < `false_alarm_max_secs: 5.0` 秒"事件 → 记为误报区。
- 命中后：该区域检测置信度 × `false_region_suppress_factor: 0.4`，降低再次误报概率。
- 安全性：真实长期停留的人（有脸或时长足够）不会被误抑；误报区数据只影响该区域。

### 3. 自适应置信度阈值（按事件质量调优）
- 依据近期事件质量（有无清晰人脸、停留时长）在 `adaptive_threshold_min: 0.25` ~ `adaptive_threshold_max: 0.55` 区间内以 `adaptive_threshold_step: 0.02` 步进调整。
- 事件质量高（清晰人脸 + 正常停留）→ 阈值向 0.25 方向放宽（更灵敏）；连续误报 → 阈值向 0.55 方向收紧（更保守）。
- 有界：永不越出区间；可一键复位。

## 数据文件与复位
- `learning_data.json`：运行时生成，含误报区域网格（`learning_grid: 6`）、自适应阈值状态、背景统计。
- 复位命令：`.venv\Scripts\python.exe watchdog.py --reset-learning`（清空学习数据，恢复默认阈值 0.35）。

## 验证建议
- 连续 3 天观察 `logs\watchdog.log` 中学习事件（误报区新增、阈值调整方向）。
- 若某区域频繁误报又没被抑制，检查该区域是否"无脸但停留超 5 秒"（如屏幕上的真人视频），适当调 `false_alarm_max_secs` 或 `false_region_repeat`。
